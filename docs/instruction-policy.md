# 지시 수행 판정과 개입 정책

이 문서는 [B-05](big-nodes/B-05.md)가 고를 산출물과 [B-06](big-nodes/B-06.md)가 허용할 표시를 연결한다. 버튼 위치 탐색의 상태는 [N-16](small-nodes/N-16.md), 모델 위치 판정은 [N-27](small-nodes/N-27.md), 수행 판정은 [N-28](small-nodes/N-28.md)에 있다.

| 우선순위 | 입력과 확인 조건 | 업무 결과 | 부모 표시 |
|---|---|---|---|
| 1 | 도움 종료/철회, 보호 화면, 오래된 mode·지시·화면, 불안정한 레이아웃 | suppressed | 테두리 및 기존 표시 제거 |
| 2 | 금지·되돌리기 어려운 조작 지시, 보호 문구 안전하게 띄울 수 있음 | policy_denied | “되돌리기 어려운 동작이에요. 천천히 확인하세요”만 표시 |
| 3 | 맞는 조작 입증, 누름 결과가 발생한 관측 시각이 3초 이내 | followed | 테두리와 안내 0회. 새 자녀 지시 대기 |
| 4 | 3초 미경과 또는 화면 변화가 있고 수행 판정 대기 | waiting | 표시 없음. 판정·안정 화면을 기다림 |
| 5 | 3초 경과 + WRONG + 현재에서 지시 원래 화면까지 확인된 역엣지 | intervene_back | “뒤로 가기”. 첫 역엣지 한 번을 안내 |
| 6 | 3초 경과 + 연속 관찰에서 입력 단서 없음 + 대상이 아래에 있다는 증거 | intervene_scroll | “화면 내리기”. 현재 스크롤 범위에서만 |
| 7 | 3초 경과 + 연속 관찰에서 입력 단서 없음 + 현재 위치에 대상 확인 | intervene_tap | 대상 빨간 테두리와 큰 글씨 |
| 8 | 불연속, 확실하지 않은 변화, 위치 미확인, 잘못 누름 확인 후 역경로 없음 | waiting | 대상 강조 없음. 통화는 유지 |

발화 끝·타이머 경과·서버 결과 수신만으로 부모님의 손을 눌렀다거나 움직이지 않았다고 단정하지 않는다. 로컬 관찰에서 의미 변화 후보가 먼저 감지되면 원을 숨기고 N-28 결과가 적용될 때까지 기다린다. 오선택과 아래 위치가 동시에 후보여도 검증된 복귀를 우선한다. 뒤로/스크롤 이후 처음 지시의 최신 대상만 새로 찾는다. 이미 닫힌 지시는 다시 열지 않는다. 3초 뒤 맞게 조작한 경우도 현재 표시를 제거하고 지시를 닫지만, 3초 이내 무표시 지표의 분모에는 들어가지 않는다.

## 결정한 것

| 결정 | P0 계약 |
|---|---|
| 3초 시작 기준 | 부모 단말이 새 정규화된 자녀 지시를 적용한 시각. 탐색 지연 및 재네트워크로 시작점 이동 없음 |
| 분기 타이밍 | 잘못 누름의 복귀 문구도 같은 3초 게이트 이후. 실제 변화 직후 기존 잘못된 테두리는 즉시 제거 |
| 부모 발화 처리 | 동의된 통화에서 역할 분리와 STT는 가능. 부모 발화는 Zoro-1 목표 확률 갱신에만 쓰고, 새 지시·스피커 전환·개입을 트리거하지 않음 |
| 첫 지시·목표 | 자녀 발화의 명시적 목표와 버튼 지시를 따로 처리. 같은 발화에서 둘 다 나온 경우 스피커 전환은 1회 |
| 통화 후 인계 | 확정 hangup에서 유효한 마지막 목표만 이어받고 통화 중 타이머는 폐기. 목표 없음은 후속 행동 대기/정리 |
| 진행 기록 | 지시의 정규화 ID, 위치 근거와 전이·판정 코드만 필요 범위에서 유지. 자녀 UI에는 도착 추정 및 완료 제어만 공개 |
