# B-05 · Zoro-1 판단과 다음 단계 선택

- **담당** C, D 협업
- **PRD 추적** B-2~B-7, C-1, C-6, C-8~C-11, D-2

허용된 목표와 화면에서 Zoro-1 System 1의 네 종류 판단을 실행한다.

| 경계 | 내용 |
|---|---|
| 입력 | 확정 발화·현재 목표·정제한 화면·이력과 후보 |
| 출력 | goal.updated, guide.proposed 또는 보류, arrival.suspected 후보 |
| 내부 계약 | [N-14](../small-nodes/N-14.md) · [N-15](../small-nodes/N-15.md) · [N-16](../small-nodes/N-16.md) · [N-17](../small-nodes/N-17.md) · [N-18](../small-nodes/N-18.md) |

## 실행 순서와 분기

| 단계 | 정상 흐름 | 조건과 실패 경로 |
|---|---|---|
| 1. 발화 판단 | 활성 목표 없음은 목표 분류부터, 활성 중에는 변경 여부부터 실행한다. 지원 목표와 슬롯은 검증한다. | 확신이 낮거나 슬롯이 비면 대기, 금지 요청은 정책 차단. |
| 2. 유효 후보 | 현재 screen_revision과 도움 상태에서 볼 수 있는 버튼과 조작만 구성한다. 이전 화면과 실제로 관찰한 전이가 있을 때 BACK 후보를 추가한다. | 등록되지 않은 버튼이나 자녀 화면 영상 전송은 후보 자체에 넣지 않는다. |
| 3. 도착 확인 | 로컬 관찰 단서가 맞을 때에만 Zoro-1에 도착 판단을 요청한다. | 긍정 확률만 높고 실제 화면 근거가 부족하면 계속 안내 또는 대기. |
| 4. 다음 단계 | 도착이 확정되지 않은 경우 typed choice에서 현재 행동 하나를 선택한다. 모델 타임아웃 시에는 현재 가이드를 유효성 기준으로 정리한다. | 재호출은 요건이 동일할 때 제한. 새로운 발화나 화면 갱신에서 재평가. |
| 5. 발행 | 최신 goal_revision과 예상 화면을 재확인해 B-06/B-07에 전달한다. | 이미 바뀐 리비전 또는 구식 선택은 폐기하고 통계만 남긴다. |

## 통과 기준

고정 모델 revision에서 실제 호출 기록을 남긴다. A는 정정과 BACK 순서, B는 통화 종료 후에도 화면 기반 안내와 도착 판단을 확인한다.
