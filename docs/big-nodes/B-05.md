# B-05 · Zoro-1 판단과 모드별 안내

- **담당** C, A·D 협업
- **PRD 추적** B-2~B-7, C-1~C-15, D-2~D-3
- **하위 노드** [N-14](../small-nodes/N-14.md) · [N-15](../small-nodes/N-15.md) · [N-16](../small-nodes/N-16.md) · [N-17](../small-nodes/N-17.md) · [N-18](../small-nodes/N-18.md) · [N-27](../small-nodes/N-27.md) · [N-28](../small-nodes/N-28.md)
- **상태** 설계 계약 확정. 실제 환경 검증 전.

## 목적과 진입 조건

CALL_CHILD_LED에서는 새 자녀 발화·안정 화면·관측된 조작 결과만 평가한다. POST_CALL_AGENT에서는 확정 hangup 이후 목표와 최신 안정 화면으로 다음 동작 또는 도착을 판단한다. N-14는 호출 모드를 한 번 더 검사한다.

## 입력 계약

| 타입 | 소유자 | 필요한 정보 |
|---|---|---|
| FinalUtterance | B-02 | 현재 자녀 확정 발화와 utterance_seq |
| HelpSnapshot/Basis | B-04 | 최신 mode, instruction/goal revision, 동의/화면 |
| ScreenState 및 NavigationTrail | B-03/B-04 | 안전한 대상 ID, 부모 관찰 건강성, 검증 이력 |

## 결과 계약

구간 결과는 `NodeResult<WorkflowData>`이며 `diagnostics.node_id=B-05`를 사용한다. 아래 데이터는 결과 경계에서 읽을 수 있는 필드다. 적용하지 않는 선택 출력은 null이며 지역 전용 값과 내부 진단을 역할 UI에 송신하지 않는다. 오류는 `outcome=null`, `data=null`이다. 하위 결과의 참조와 생략된 단계는 [공통 Diagnostic](../node-result-contract.md)에 남긴다.

| 필드 및 타입 | 값 또는 책임 |
|---|---|
| instruction_draft, goal_draft: 양쪽 nullable | N-15가 산출, N-11에 채택 요청 |
| target: TargetDecision? | N-27에서 위치 검증, 부모에 ID만 전달 |
| verdict: ActionVerdict? | N-28이 수행을 판단하고 N-19와 N-11에 전달 |
| recovery: RecoveryHint? | 검증한 역방향 경로에서 한 단계 복귀 근거 |
| guide: GuideProposal? | 통화 후 N-17의 단일 행동 후보 |
| arrival: ArrivalDecision? | 통화 후 N-18에서만 N-22 전달 |

## 호출 및 검증 정책

1. N-15: 최신 자녀 확정문만. 목표·버튼 해석을 독립 적용한다. 지시 초안이 준비되면 목표 모델 응답 전에 N-11에 전송한다. 부모 발화에서 새 지시·목표·모델 호출 0회.
2. N-27: N-16이 완료한 현재/아래 후보 또는 부분 검색의 직접 확인 후보가 있을 때만. 위치는 마감 전에 준비하고 표시하지 않음.
3. N-28: 현재 지시 뒤 실제 전후 관측 근거가 생길 때만. 결과 CORRECT는 표시 취소, WRONG은 N-16 역엣지 확인, UNKNOWN은 보류.
4. N-18/N-17: POST_CALL_AGENT만. N-18은 목표별 도착 증거에서만 호출. 도착 추정 시 N-17 생략. 증거 없음 또는 not_arrived라면 현재 후보가 있을 때 N-17.
5. 각 결과를 커밋하거나 부모·자녀에 넘기기 직전에는 관련 Basis를 검사. 모드, 목표/지시, 동의, 화면, epoch 스코프를 각각 비교.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| success | live_evidence_ready | 현재 지시의 위치 또는 수행 근거를 검증 | B-06가 시간과 입력을 최종 검증 |
| success | goal_captured | 현재 명시 목표와 슬롯을 채택 | 통화 중 목표만으로 테두리 예약 없음 |
| success | post_action_ready | 통화 후 유효 목표에서 선택지 하나 판단 | 나머지 행동은 새 관측까지 기다림 |
| success | post_arrival | 통화 후 근거와 모델 판단 일치 | N-22에 도착 추정만 전달 |
| success | waiting | 안전한 후보 없음, 보호 또는 현재 증거 부족 | N-16 상태는 그대로 진단에 보존. 표시 보류 |
| partial | search_incomplete | 일부 검색·판단 실패로 검증 범위 제한 | N-16이 검증한 현재 후보만 전달 가능 |
| error | null | 안전한 출력 만들 수 없는 모델 오류 또는 스코프 불일치 | 구식 안내 적용 금지, 오류와 낮은 확신 분리 |
