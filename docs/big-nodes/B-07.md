# B-07 · 역할별 상태 전달·완료·삭제

- **담당** D, A·B 협업
- **PRD 추적** C-10, D-4, E-3, F-1~F-5, G-1~G-3

양쪽에 목표를 전하고 자녀의 확정 또는 부모 중단에서 도움을 정리한다.

| 경계 | 내용 |
|---|---|
| 입력 | goal.updated·arrival·완료 명령·안내 끄기 |
| 출력 | 양쪽 상태, 중복 없는 도착 알림, help.ended |
| 내부 계약 | [N-21](../small-nodes/N-21.md) · [N-22](../small-nodes/N-22.md) · [N-23](../small-nodes/N-23.md) |

## 실행 순서와 분기

| 단계 | 정상 흐름 | 조건과 실패 경로 |
|---|---|---|
| 1. 역할별 표시 | 자녀에게 현재 목표, 도착 추정과 완료 버튼만 보내고 부모에게는 상단 띠와 안내 전달을 한다. | 자녀 앱에도 화면 영상을 구독·조회하는 UI를 제공하지 않는다. |
| 2. 도착 추정 | 버전이 일치하는 판단을 도착 알림으로 전환한다. 도움은 유지한다. | 같은 순서에서 중복 알림을 보내지 않는다. 결과가 바뀌면 알림을 정정한다. |
| 3. 완료/중단 | 인증된 자녀 명령 또는 부모 안내 끄기를 받아 help_id 상태를 한 번만 종료한다. | 이전 도움 완료 명령은 다음 도움을 종료할 수 없다. |
| 4. 삭제 | 가이드·타이머·캡처·진행 이력·음성 대기열을 지운다. 자녀 완료일 때 부모에게 완료 문구를 띄운다. | 통화가 살아 있으면 사전 동의에 따라 새 목표를 기다릴 수 있다. 새 도움에 이전 도움의 내용을 재사용하지 않는다. |

## 통과 기준

통화 종료 후 자녀 첫 화면의 완료 버튼이 살아 있고, 중복 동작·완료 없는 도착·부모 취소의 화면 결과가 구별돼야 한다.
