# B-06 · 부모님 표시와 모드별 3초 게이트

- **담당** A, D 협업
- **PRD 추적** C-1~C-13, E-1, E-3~E-4
- **하위 노드** [N-19](../small-nodes/N-19.md) · [N-20](../small-nodes/N-20.md)
- **상태** 설계 계약 확정. 실제 환경 검증 전.

## 목적과 진입 조건

부모에서 새 지시 수신·목표/모드·화면 변화·마감 틱·중단에 반응한다. N-19가 화면과 단조 시각을 검증하고 N-20이 유효한 로컬 표시만 그린다.

## 입력 계약

| 타입 | 소유자 | 필요한 정보 |
|---|---|---|
| Instruction 또는 Goal와 Basis | B-04 | 활성 모드, 버전 및 부모 적용 이벤트 |
| TargetDecision/ActionVerdict/RecoveryHint 또는 GuideProposal | B-05 | 통화 중 관찰 근거/통화 후 선택 |
| LocalObservation | B-03 | 좌표, 최신 캡처 시각과 layout_revision |

## 결과 계약

구간 결과는 `NodeResult<WorkflowData>`이며 `diagnostics.node_id=B-06`를 사용한다. 아래 데이터는 결과 경계에서 읽을 수 있는 필드다. 적용하지 않는 선택 출력은 null이며 지역 전용 값과 내부 진단을 역할 UI에 송신하지 않는다. 오류는 `outcome=null`, `data=null`이다. 하위 결과의 참조와 생략된 단계는 [공통 Diagnostic](../node-result-contract.md)에 남긴다.

| 필드 및 타입 | 값 또는 책임 |
|---|---|
| display: LocalGuide? | 검증된 테두리 또는 문구 명령. 좌표는 부모 내부 |
| rendered: boolean | N-20 실제 표시 여부 |
| reason: enum | B-04에 guide.shown/suppressed 근거와 경과시간 |

## 호출 및 검증 정책

1. 통화 중 타이머는 새 지시 최초 적용에서만 재예약. 화면 전환은 현재 위치 무효화·조작 판정 대기만 유발.
2. 통화 후에만 모드 적용 뒤 안정 의미 화면마다 3초. 이전 모드의 타이머/제안은 취소.
3. 위험 요청은 지정 보호 문구만. 검증 가능한 입력이 마감과 같은 시각이면 표시보다 먼저 처리.
4. 캡처 철회·보호 화면·오래된 layout·판정 미확정에는 N-20 clear 우선. 터치 실패하면 창 제거.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| success | shown | 유효 근거와 표시 허용 정책 충족 | 현재 행동 안내만 표시하고 상태 전송 |
| success | suppressed | 정답, 시각 미도달, 위임 대기 또는 종료 | 표시는 0회 또는 기존 표시 제거 |
| success | policy_denied | 조작이 금지/위험 범위 | 안전한 곳에서 지정 문구만 |
| partial | banner_only | 좌표나 OS 차단으로 강조 불가, 안전한 부모 띠만 허용 | 자동 Overlay 성공에서 제외 |
| error | null | 권한 실패, 잘못된 스코프 또는 터치 방해 | 창 제거, 실패 이유 전송 |
