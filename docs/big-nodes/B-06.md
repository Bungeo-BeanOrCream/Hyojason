# B-06 · 부모님 안내 표시와 3초 제어

- **담당** A, D 협업
- **PRD 추적** C-2~C-6, C-8~C-9, E-1, E-3~E-4

한 대상만 빨간 테두리와 큰 문구로 표시하고 터치 조작을 보존한다.

| 경계 | 내용 |
|---|---|
| 입력 | 선택 제안, 목표 및 화면·캡처 버전, 오래되지 않은 위치와 로컬 시각 |
| 출력 | 부모 Overlay/상단 띠, shown/suppressed 상태 |
| 내부 계약 | [N-19](../small-nodes/N-19.md) · [N-20](../small-nodes/N-20.md) |

## 실행 순서와 분기

| 단계 | 정상 흐름 | 조건과 실패 경로 |
|---|---|---|
| 1. 트리거 | 목표 확정·변경 또는 의미 있는 화면 전이에서 즉시 이전 테두리를 제거하고 로컬 3초를 예약한다. | 스크롤·IME·좌표가 흔들리면 표시를 숨기고 다시 확인한다. |
| 2. 표시 검증 | 타이머, 활성 도움, Overlay 권한, 현재 화면과 부모 로컬 좌표, 보호 화면 여부를 모두 확인한다. | 권한 없음·기한 만료·오래된 제안은 렌더하지 않으며 억제 이유를 보낸다. |
| 3. 표시 | 부모 창에는 접촉하지 않는 빨간 강조를 표시한다. 별도 상단 띠로 상대, 목표, 안내 끄기를 제공한다. | 띠의 터치 영역은 띠 내부에 제한하고 그 아래 화면의 조작을 검증한다. |
| 4. 정리 | 세션 종료·차단·새 의미 전이 발생 즉시 표시를 제거한다. | 부모가 직접 안내 끄기를 탭하면 로컬부터 정리한다. 성공 문구는 자녀 완료 확인 시에만 짧게 표시한다. |

## 통과 기준

설정과 시계의 실제 버튼 위에서 터치가 통과하며 이전 화면의 위치, 최신 화면 밖의 위치, 승인 철회 뒤 표시가 없어야 한다.
