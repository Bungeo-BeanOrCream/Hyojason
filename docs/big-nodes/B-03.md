# B-03 · 부모 화면 관찰과 전이 확정

- **담당** A, D 협업
- **PRD 추적** C-1, C-4, C-8, D-1, F-3, H-3

동의한 화면을 단말에서 처리해 검증 가능한 화면·대상·완료 단서만 전달한다.

| 경계 | 내용 |
|---|---|
| 입력 | MediaProjection 프레임, 기기 UI 설정, 앱별 검증 프로필 |
| 출력 | screen.observed, 부모 로컬 좌표, capture 건강 상태 |
| 내부 계약 | [N-07](../small-nodes/N-07.md) · [N-08](../small-nodes/N-08.md) · [N-09](../small-nodes/N-09.md) · [N-10](../small-nodes/N-10.md) |

## 실행 순서와 분기

| 단계 | 정상 흐름 | 조건과 실패 경로 |
|---|---|---|
| 1. 승인·시작 | 두 앱 Demo는 사용자 승인 전체 화면 캡처를 사용해 Home과 5개 앱을 오간다. 동의와 포그라운드 서비스 순서, 재사용하지 않는 캡처 ID를 준수한다. | 사용자가 거절하거나 프로젝션이 종료되면 캡처 결과를 보내지 않는다. |
| 2. 정규화 | 원본은 메모리에서만 처리한다. 화면/레이아웃 안정성, 회전·inset 및 Overlay 자기 마커를 고려해 실제 사용 가능한 영역을 분리한다. | 민감 화면, 보호 화면, 미확인 화면은 좌표·완료 단서 없이 관찰 공백으로 처리한다. |
| 3. 탐지 | 한국어 라벨과 아이콘·컨트롤 조합으로 화면을 분류하고 현재 보이는 검증된 후보만 반환한다. | 좌표는 로컬 보관. 등록되지 않은 OCR 텍스트, 개인 데이터나 원본 프레임은 서버에 전송하지 않는다. |
| 4. 전이 | 부모가 실제 화면을 바꾼 뒤 의미 변화·레이아웃 변화·건강 상태를 분류한다. | 위치만 바뀌면 배치를 재검증, 바뀐 화면은 원을 즉시 치우고 새 screen_revision 발행. |

## 통과 기준

Settings와 Clock에서 서로 다른 버튼이 감지되며 Gmail 계정 정보나 프레임이 제어 채널에 없는지 확인한다. 공통 탐지 코드를 공유하고 앱별 UI 검증 프로필만 바꾼다.
