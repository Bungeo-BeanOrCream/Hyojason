# B-04 · 도움 상태와 방문 이력

- **담당** D, A·B 협업
- **PRD 추적** D-1~D-2, D-4, G-1~G-3

통화와 도움의 생명주기를 나누고 이후 재판단을 위한 현재 위치와 검증된 경로를 유지한다.

| 경계 | 내용 |
|---|---|
| 입력 | call·consent·speech·screen·goal·completion 이벤트 |
| 출력 | 현재 도움 상태, 활성 revision, 최근 확인 지점, 재접속 snapshot |
| 내부 계약 | [N-11](../small-nodes/N-11.md) · [N-12](../small-nodes/N-12.md) · [N-13](../small-nodes/N-13.md) |

## 실행 순서와 분기

| 단계 | 정상 흐름 | 조건과 실패 경로 |
|---|---|---|
| 1. 이벤트 수락 | 인증·역할·도움 ID와 순서를 확인하고 per-help 단일 처리 경로에서 상태를 갱신한다. | 동일 event_id 및 종료된 help_id는 멱등 또는 거절로 처리한다. |
| 2. 이력 | screen_revision 변화와 이전 검증 화면, 관찰된 진행 근거를 메모리에 순서대로 보존한다. | 원본 사진/메일/발화는 이력에 저장하지 않는다. 스크롤·알림창만으로 성공한 업무 단계로 분류하지 않는다. |
| 3. 정정 | goal_revision이 증가하면 도착 추정을 취소하고 B-05에 재평가를 요청한다. | 기존 단계 중 새 목표에 유효한 정보는 남기고, 화면과 무관한 항목을 무효화한다. |
| 4. 통화만 종료 | 확정 목표가 있을 때 B-02의 STT를 멈추고 GUIDING을 유지한다. | 목표 없음은 정리. 살아 있는 도움만 최신 관찰을 받고 자녀의 완료를 기다린다. |
| 5. 재연결 | 각 역할이 해당 도움의 최신 snapshot을 받는다. | 연결 공백은 상태에 표시하고 UI 명령을 재생하지 않는다. 새 화면 검증 전 표시를 멈춘다. |

## 통과 기준

동일 help_id에서 통화 종료 뒤 목표 유지, 재접속, 도움 삭제와 새 도움의 독립성까지 검증한다.
