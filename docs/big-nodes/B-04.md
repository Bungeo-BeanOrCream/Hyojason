# B-04 · 도움 상태와 방문 이력

- **담당** D, A·B 협업
- **PRD 추적** D-1~D-4, G-1~G-3
- **하위 노드** [N-11](../small-nodes/N-11.md) · [N-12](../small-nodes/N-12.md) · [N-13](../small-nodes/N-13.md)
- **상태** 설계 계약 확정. 실제 환경 검증 전.

## 목적과 진입 조건

도움 상태를 바꾸는 인증된 이벤트와 재연결 조회 요청에서 실행한다. 한 도움에 한 이벤트 작성 순서를 적용하고 늦은 결과는 스코프별 최신 조건으로 비교한다. 현재 지시, 목표, 모드를 각각 독립 작성한다.

## 입력 계약

| 타입 | 소유자 | 필요한 정보 |
|---|---|---|
| Event | B-01/02/03/05/06/07 | event_id, 역할, 타입, 검증된 basis와 payload |
| HelpSnapshot? | 서버 상태 | 현재 목표, 통화·도움 상태, 최신 화면 요약 |
| Transition, InstructionTrace 또는 ResumeRequest | screen.observed, 채택한 지시·위치·수행 또는 제어 재접속 | 원래/현재 화면, 정규화 지시와 위치 근거, 역할 |

## 결과 계약

구간 결과는 `NodeResult<WorkflowData>`이며 `diagnostics.node_id=B-04`를 사용한다. 아래 데이터는 결과 경계에서 읽을 수 있는 필드다. 적용하지 않는 선택 출력은 null이며 지역 전용 값과 내부 진단을 역할 UI에 송신하지 않는다. 오류는 `outcome=null`, `data=null`이다. 하위 결과의 참조와 생략된 단계는 [공통 Diagnostic](../node-result-contract.md)에 남긴다.

| 필드 및 타입 | 값 또는 책임 |
|---|---|
| snapshot: HelpSnapshot? | N-11의 최신 서버 상태 |
| trail: NavigationTrail? | N-12 승인된 엣지·공백·지시 및 위치 근거를 담음 |
| role_snapshot: RoleSnapshot? | N-13 재연결 역할 투영 |
| effects: EffectRef[] | 명시적 소속과 최신 버전을 가진 후속 작업 |

    apply -->|적용| update{"안정 전이·공백·지시 증거 기록이 필요한가?"}
    update -->|예| trail["N-12 전이·공백 또는 지시 근거 기록"]

## 호출 및 검증 정책

1. 같은 help_id·event_id 재전송 → N-11 처리 결과만 확인. 적용 seq와 부수 효과 증가 금지.
2. 안정 화면 도착 및 전이 근거 있음/없음 → N-12 실측 엣지 추가/공백 마커. speech.final 또는 TTL 틱만으로는 N-12 미호출.
3. N-15 명시 목표 초안 → N-11이 최신 발화와 help 상태를 확인하고 유효 목표·슬롯이 달라진 경우에만 goal_revision을 증가시킨다. 버튼 지시와 목표의 적용을 따로 판단한다.
4. 재연결 → N-13 최신 역할 스냅샷. 부모가 새 화면을 관찰하기 전에는 표시 재생 금지.
5. N-15가 새 자녀 지시 발행 → N-11이 instruction_revision을 증가시켜 이전 지시를 폐기하고 B-06에 전달. 부모 발화는 변경하지 않음.
6. 지시 채택·위치 결과·수행 결과가 현재 스코프에서 적용되면 N-12에 근거만 추가한다. 인증/스크린 보호/최신성 검증이 실패한 결과로 기존 이력을 덮지 않는다.
7. RTC 일시 순단은 STT/표시 보류. 확정 hangup에만 최근 유효 목표와 POST_CALL_AGENT 적용.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| success | applied | 새 이벤트가 역할과 스코프를 만족 | 해당 효과를 한 번만 게시 |
| success | snapshot_served | 인가 역할의 재연결 조회 완료 | 이전 클릭 안내 없이 재관찰 |
| success | ignored | 중복, 이미 처리한 효과, 종료 ID의 정상 재요청 | 현재 상태 유지, 효과 없음 |
| partial | trace_gap | 안전한 화면·도움 상태는 있으나 연속 전이 근거 없음 | 복귀 탐색 경로에 공백 표시 |
| error | null | 제3자, 유효 범위 위반 또는 필수 상태 쓰기 실패 | 비인가 갱신 금지. 최신 저장 상태에서 새 이벤트만 수락 |

## 최소 테스트와 기대 결과

| ID | 재현 조건 | 기대 결과 |
|---|---|---|
| B04.1 | speech.final과 goal.updated가 중복·역전 입력 | 최신 utterance_seq에서 채택한 목표만 반영, revision 1회 증가 |
| B04.2 | clock 도움 도중 call.ended | call_state=ENDED 및 mode=POST_CALL_AGENT 및 help_state 진행 상태 유지. N-12나 N-19를 RTC 종료만으로 중단하지 않음 |
| B04.3 | 화면 A → 캡처 공백 → 화면 B | A → B를 근거 엣지로 추가하지 않음. N-16은 공백을 넘지 않음 |
| B04.4 | 재연결 전에 제안 저장, 이후 부모 재관찰 | N-13 응답에 재생할 제안/좌표 없음. 새 화면 이벤트 이후에만 B-05 재평가 |
