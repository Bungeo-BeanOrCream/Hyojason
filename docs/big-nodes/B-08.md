# B-08 · AVD·GPU 운영·검증·시연

- **담당** D, C 모델 담당
- **PRD 추적** PRD pp. 9–11 · 성공 기준

측정과 확인에 필요한 도구·시연 조건을 만들고 실제 성공 여부를 분리한다.

| 경계 | 내용 |
|---|---|
| 입력 | AVD/앱 버전, 두 역할 테스트 항목, GPU 차감, 테스트 trace |
| 출력 | 앱별 재현 경로, 정상·오류 테스트 결과, 예산과 최종 데모 |
| 내부 계약 | [N-24](../small-nodes/N-24.md) · [N-25](../small-nodes/N-25.md) · [N-26](../small-nodes/N-26.md) |

## 실행 순서와 분기

| 단계 | 정상 흐름 | 조건과 실패 경로 |
|---|---|---|
| 1. 환경 확인 | 두 AVD·마이크·화면 보호·네트워크·로그 상태를 기본 점검표로 확인한다. | 통화/공유가 막히면 오류를 기록하고 샘플 경로와 실제 단말 결과를 구분한다. |
| 2. 계약·통합 시험 | 두 라이브 장면과 5개 앱 목표를 개별 실행하고 정정, 권한 철회, stale 결과, 중복 완료를 재현한다. | 성공 여부를 기능마다 집계. 1개 케이스를 전체 앱 지원으로 해석하지 않는다. |
| 3. 측정 | 팀의 20개 대화 예시, 5회씩 리허설, 3초 안내와 5초 목표 갱신을 기록한다. | 동영상·로그는 테스트 자산만 사용하며 민감한 원본은 저장하지 않는다. |
| 4. 비용·리허설 | 실제 Zoro 모델, L40S 비용, 고정 버전과 최종 데모 증거를 관리한다. | 장애에는 저장된 실제 시험 증거 또는 명시적 대체 안내를 쓰고 성공 조건은 그대로 기록한다. |

## 통과 기준

다섯 앱 지원표, 설정과 시계의 반복 성공률, 실제 모델 provenance, GPU 사용 기록을 모두 남긴다.
