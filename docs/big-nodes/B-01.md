# B-01 · 가족 연결·통화·동의

- **담당** B, A 협업
- **PRD 추적** A-1~A-4, E-2, H-1~H-2

승인된 1:1 관계에서 부모 발신을 받아 동의된 음성통화를 시작한다.

| 경계 | 내용 |
|---|---|
| 입력 | pair 승인 상태, 각 역할의 동의와 RTC 수락/연결 상태 |
| 출력 | call_id, 양쪽 접속 상태, STT 시작 가능 신호 |
| 내부 계약 | [N-01](../small-nodes/N-01.md) · [N-02](../small-nodes/N-02.md) · [N-03](../small-nodes/N-03.md) |

## 실행 순서와 분기

| 단계 | 정상 흐름 | 조건과 실패 경로 |
|---|---|---|
| 1. 시작 | 부모 화면의 자녀 사진 1개에서 발신한다. 서버가 pair 소속을 확인하고 연결된 자녀 화면으로 수신 상태를 전달한다. | 이미 ringing/active면 중복 방을 만들지 않는다. |
| 2. 수신·동의 | 자녀 수락, 양쪽 음성/화면 안내 동의, 권한을 별도 조건으로 확인한다. | 수신 거절은 즉시 정리. 안내 동의가 없으면 분석과 캡처를 시작하지 않는다. |
| 3. 연결 | 역할별 LiveKit 토큰과 마이크를 준비한다. 실제 통화 연결이 확인되면 B-02로 시작 이벤트를 보낸다. | 연결 오류·수락 만료를 각각 표시한다. 연결되지 않은 통화를 활성 상태로 내보내지 않는다. |
| 4. 전환 | 부모가 Settings/Clock으로 전환하는 동안 통화 서비스를 유지한다. 도움 시작 시 이어폰을 우선하고 그 외 스피커폰을 시도한다. | 권한·오디오 라우팅 예외는 상태를 보여 주고 시스템 기본 경로를 사용한다. |
| 5. 통화 종료 | call.ended를 제어 서버에 보내고 RTC를 정리한다. | 도움 종료는 B-07이 처리한다. 목표가 있으면 제어 채널과 부모 캡처를 그대로 유지한다. |

## 통과 기준

양쪽 AVD에서 실제 상대 발화가 들리고 A-4 앱 전환과 두 역할의 동의 철회가 확인돼야 한다. P0에서는 부모 발신만 라이브 동선으로 고정한다.
