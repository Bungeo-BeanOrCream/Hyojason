# B-01 · 가족 연결·통화·동의

- **담당** B, A 협업
- **PRD 추적** A-1~A-4, E-2, H-1~H-2
- **하위 노드** [N-01](../small-nodes/N-01.md) · [N-02](../small-nodes/N-02.md) · [N-03](../small-nodes/N-03.md)
- **상태** 설계 계약 확정. 실제 환경 검증 전.

## 목적과 진입 조건

페어 승인, 발신/수락, 동의 변경, RTC 상태 콜백, 첫 자녀 지시·목표에서 실행한다. 인증 주체를 먼저 잠그고, 방 상태가 연결될 때까지 STT 시작 신호를 보내지 않는다. 첫 확정 자녀 지시 또는 유효 목표에서만 N-03 오디오 경로 갱신을 요청한다.

## 입력 계약

| 타입 | 소유자 | 필요한 정보 |
|---|---|---|
| PairRequest 또는 PairView | 제어 서버/N-01 | 인증 역할, pair_id, 승인 상태 |
| ConsentUpdate 또는 ConsentView | 양쪽 앱/N-02 | 목적별 enabled, consent_revision, capture/overlay 가능 여부 |
| RtcEvent | LiveKit/N-03 | call_id, room state, 연결 역할, 오디오 경로 |
| FirstChildDirective | N-11 | 첫 자녀 지시 또는 목표 확인. call_id당 한 번 평가 |

## 결과 계약

구간 결과는 `NodeResult<WorkflowData>`이며 `diagnostics.node_id=B-01`를 사용한다. 아래 데이터는 결과 경계에서 읽을 수 있는 필드다. 적용하지 않는 선택 출력은 null이며 지역 전용 값과 내부 진단을 역할 UI에 송신하지 않는다. 오류는 `outcome=null`, `data=null`이다. 하위 결과의 참조와 생략된 단계는 [공통 Diagnostic](../node-result-contract.md)에 남긴다.

| 필드 및 타입 | 값 또는 책임 |
|---|---|
| pair: PairView | 승인된 쌍과 대기 상태 |
| consent: ConsentView? | 적용된 동의와 기기 권한 |
| call: CallState? | call_id, 현재 RTC 상태, 통화 종료 사유 |
| speech_gate: OPEN 또는 CLOSED | B-02 시작과 종료를 지시하는 계산 상태 |

## 호출 및 검증 정책

1. 페어 pending → N-02 조회 가능, N-03 방 생성 금지; 다음 승인 이벤트 대기.
2. 상대 수락과 양쪽 RTC 참가 및 양쪽 처리 동의 → B-02 시작과 B-04 평가; 같은 콜백 재수신은 no-op.
3. 통화 연결 중 STT 동의 철회 → B-02 종료, B-04 조정을 요청; RTC와 별도 처리.
4. call.ended → B-02 STT 버퍼 폐기, B-04 call 상태 반영; help.stop 합성 금지.
5. 첫 자녀 지시/목표 → N-03 스피커폰 경로 1회 평가. Bluetooth 또는 유선 이어폰은 기존 경로 유지.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| success | speech_open | 양쪽 연결과 처리 동의 유효 | 룸의 참가자 역할만 B-02에서 받음 |
| success | waiting | 승인·수락·RTC 참가가 아직 부족 | 다음 이벤트만 기다림 |
| success | voice_only | RTC 연결, Agent 처리 동의 부족 | 음성 연결 유지. STT/캡처 시작 금지 |
| success | call_closed | RTC 종료 확인 | 음성 처리만 종료. 도움 상태는 B-04 판정 |
| partial | rtc_degraded | 상대/RTC 상태 일부 단절, 검증된 승인 상태 남음 | 새 오디오 처리 없이 RTC 재접속 신호 대기 |
| error | null | 승인·서명·페어 불일치 또는 필수 방 연결 실패 | 토큰·오디오 전송 금지. 원인 코드 기록 |

## 최소 테스트와 기대 결과

| ID | 재현 조건 | 기대 결과 |
|---|---|---|
| B01.1 | 부모 AVD 발신 및 자녀 AVD 수락, 양쪽 동의 | 같은 call_id. 양쪽 음성 교환 후 speech_open을 한 번만 발행 |
| B01.2 | 자녀 승인 또는 처리 동의 하나를 제외 | 승인 미비면 방 0개. 동의만 미비하고 연결되면 voice_only 및 STT 0개 |
| B01.3 | 다른 페어 또는 중복 accept | 다른 페어 UNAUTHORIZED, 중복에는 새 방·토큰 요청·Agent 시작 효과 없음 |
| B01.4 | 활성 도움과 RTC에서 자녀가 끊기 | speech_gate=CLOSED와 call.ended. B-04의 help_id는 유지 |
