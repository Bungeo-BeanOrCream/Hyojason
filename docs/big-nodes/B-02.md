# B-02 · 음성 수신과 한국어 지시 확정

- **담당** B, C 협업
- **PRD 추적** B-1~B-7, H-2~H-3
- **하위 노드** [N-04](../small-nodes/N-04.md) · [N-05](../small-nodes/N-05.md) · [N-06](../small-nodes/N-06.md)
- **상태** 설계 계약 확정. 실제 환경 검증 전.

## 목적과 진입 조건

B-01의 speech_gate가 OPEN이고 call_id·consent_revision이 최신이어야 PCM을 읽는다. RTC 꺼짐 또는 동의 철회가 STT 내부 버퍼 출력보다 먼저 적용된다.

## 입력 계약

| 타입 | 소유자 | 필요한 정보 |
|---|---|---|
| CallState/ConsentView | B-01 | 활성 call_id, 역할 매핑과 consent_revision |
| AudioChunk | 승인 LiveKit track | sequence와 메모리 PCM |
| SttResult | 현재 turn | 부분/확정, 역할, 발화 종료 시각 |

## 결과 계약

구간 결과는 `NodeResult<WorkflowData>`이며 `diagnostics.node_id=B-02`를 사용한다. 아래 데이터는 결과 경계에서 읽을 수 있는 필드다. 적용하지 않는 선택 출력은 null이며 지역 전용 값과 내부 진단을 역할 UI에 송신하지 않는다. 오류는 `outcome=null`, `data=null`이다. 하위 결과의 참조와 생략된 단계는 [공통 Diagnostic](../node-result-contract.md)에 남긴다.

| 필드 및 타입 | 값 또는 책임 |
|---|---|
| utterance: FinalUtterance? | N-06 확정 이벤트. 확정문은 처리 중 전달만 허용 |
| stream_state: LISTENING 또는 DEGRADED 또는 CLOSED | B-04 상태 요약 |
| dropped_count: int | 중복/순서 불일치 등 안전한 계수 |

## 고정 워크플로우

~~~mermaid
flowchart TD
    audio["LiveKit 프레임"] --> gate{"통화·동의·참가자 유효?"}
    gate -->|유효| bind["N-04 역할 확인과 버퍼링"]
    gate -->|종료·철회| close["STT 취소와 휘발성 버퍼 제거"]
    bind --> recognize["N-05 한국어 STT"]
    recognize --> finalText{"확정 문장인가?"}
    finalText -->|부분| waitText["다음 프레임 대기"]
    finalText -->|확정| order["N-06 중복, 순서, 최신 동의 검사"]
    order -->|한 번만| emit["speech.final을 B-04로 전달"]
    order -->|무효| drop["출력 폐기"]
~~~

## 노드 간 데이터 전달

~~~mermaid
flowchart LR
    rtc["LiveKit 참가자별 PCM"] --> bind["N-04 역할별 로컬 버퍼"]

    stt -->|FinalUtterance 후보| normalize["N-06"]
~~~

## 호출 및 검증 정책

1. N-04 audio_ready → N-05 실행; unknown/duplicate/closed → N-05 금지.
2. N-05 transcribed → N-06 실행. partial 또는 timeout에서는 목표를 변경하지 않음.
3. N-06 final_committed → N-11 최신성 검사. 두 역할 모두 N-15 호출(목표 확률 갱신). 부모 확정문은 지시·타이머 트리거 없음.
4. call.ended·철회 처리 뒤 같은 call_id의 모든 늦은 확정·PCM 폐기. 새 call_id만 새로운 음성 처리 스코프.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| success | final_emitted | 활성 통화에 처음 들어온 유효 확정 발화 | B-04에 단일 전달 |
| success | listening | 부분 전사, 확정 대기 또는 중복 | 새 목표 호출 없음 |
| success | closed | Hangup 또는 처리 동의 철회 | 버퍼 및 구독 종료 |
| partial | degraded | 일부 트랙·윈도 실패, 다른 승인 역할 처리 가능 | 실패한 구간은 확정문으로 생성하지 않음 |
| error | null | 다른 통화의 데이터, 비인가 track, 전체 STT 처리 불가 | 발화 이벤트 금지. DEGRADE/CLOSED 상태를 B-04 재확인 |

## 최소 테스트와 기대 결과

| ID | 재현 조건 | 기대 결과 |
|---|---|---|
| B02.1 | 두 역할이 번갈아 같은 문장 말하기 | 역할이 각각 일치하는 speech.final 두 건 |
| B02.2 | 중간 전사 3번과 같은 turn 확정 2번 | 확정 1건만 N-15. raw PCM과 텍스트 로그 0건 |
| B02.3 | 확정 콜백 직전에 RTC 종료 | 실행 중 STT 취소. 이전 call_id의 speech.final 0건 |
| B02.4 | 한 역할 STT 고장 또는 전체 서비스 timeout | 각각 degraded와 error. 모호함으로 재분류하지 않고 RTC 상태 보존 |
| B02.5 | 부모 음성으로 ‘뒤로 가는 거야?’ 항목 발화 | 역할이 부모로 확인되고 N-15·개입 및 스피커 전환 0회 |
