# B-02 · 음성 수신과 한국어 지시 확정

- **담당** B, C 협업
- **PRD 추적** B-1~B-6, H-2~H-3

부모·자녀의 실제 통화 오디오를 역할별로 읽고 확정 발화만 전달한다.

| 경계 | 내용 |
|---|---|
| 입력 | 승인된 LiveKit 방과 참가자 오디오, call_state, 동의 |
| 출력 | 역할과 순서가 있는 speech.final, 입력 종료/중단 신호 |
| 내부 계약 | [N-04](../small-nodes/N-04.md) · [N-05](../small-nodes/N-05.md) · [N-06](../small-nodes/N-06.md) |

## 실행 순서와 분기

| 단계 | 정상 흐름 | 조건과 실패 경로 |
|---|---|---|
| 1. 수신 | RTC가 ACTIVE이고 두 역할 동의가 해결되면 지정된 두 내장 마이크 트랙만 역할로 구분해 수신한다. | 다른 RTC 참가자/영상·화면트랙은 입력 경로에 넣지 않는다. |
| 2. 분할·인식 | 역할별 버퍼의 발화 종료를 잡아 한국어 STT를 실행한다. 첫 경로는 승인된 STT 또는 CPU 로컬 엔진으로 검증한다. | 비용·처리 위치·보관 조건을 확인한다. 부분 문장은 상태 업데이트만 하고 추론에는 전달하지 않는다. |
| 3. 확정 | 발화 쪼개짐과 반복 결과를 합치고 고유 ID가 있는 최종 한 건을 서버에 전달한다. | 겹친 발화의 단서가 부족하면 추정을 보류. 텍스트 시험 주입은 trace에 manual_test로 구분한다. |
| 4. 종료 | 통화 종료를 받는 즉시 새 바이트 수신을 막고 pending 응답을 폐기한다. | 마지막 목표 이후 음성은 사용하지 않는다. 기존 도움은 B-04가 이어서 처리한다. |

## 통과 기준

부모·자녀 발화 2건을 별도 역할로 확인하고, hangup 또는 동의 철회 이후 확정 발화 0건을 검증한다.
