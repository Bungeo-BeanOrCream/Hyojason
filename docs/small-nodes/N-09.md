# N-09 · detect_screen_and_targets

- **위치와 담당** A · Android, D 검증
- **상위 노드** [B-03](../big-nodes/B-03.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

지원 screen_kind와 현재 보이는 검증 가능한 후보·근거만 반환한다.

| 경계 | 계약 |
|---|---|
| 입력 | LocalFrame, 검증된 화면/대상 레지스트리와 한국어 라벨 |
| 출력 | LocalObservation(screen_kind, target_boxes, verified_signals, certainty) |

## 처리 규칙

- 기기 공통 OCR/아이콘/배치 특징을 사용하고 Home·Settings·Clock·Maps·Messages·Gmail의 작은 시연 경로를 검증한다.
- 실제 보이는 영역의 승인된 후보 ID를 만든다. 똑같은 라벨이 두 개면 위치/화면 문맥으로 식별해야 하며 그렇지 못하면 대기한다.
- 완료 근거는 현재 선택/알람 카드/지도 도착 화면/송신 상태/메일 상세의 비민감 신호다. 가린 행, 위험 동작, 임의 OCR 본문은 후보에 추가하지 않는다.

## 오류 및 보류

미지원 화면/낮은 확신/동일 위치 후보 충돌 시 no_target 또는 unknown.

디스플레이 메뉴와 시간 제한 목록, 알람 편집과 저장 카드에서 서로 다른 후보와 검증 신호가 나오는지 확인.
