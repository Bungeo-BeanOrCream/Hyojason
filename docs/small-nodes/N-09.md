# N-09 · detect_screen_and_targets

- **위치와 담당** A · Android, D 검증
- **상위 노드** [B-03](../big-nodes/B-03.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

지원 screen_kind와 현재 보이는 검증 가능한 후보·근거만 반환한다.

| 경계 | 계약 |
|---|---|
| 입력 | LocalFrame, 검증된 화면/대상 레지스트리와 한국어 라벨 |
| 출력 | LocalObservation(screen_kind, target_boxes, verified_signals, certainty) |

## 처리 규칙

- 기기 공통 OCR/아이콘/배치 특징을 사용하고 Home·Settings·Clock·Maps·Messages·Gmail의 작은 시연 경로를 검증한다.
- 실제 보이는 영역의 승인된 후보 ID를 만든다. 똑같은 라벨이 두 개면 위치/화면 문맥으로 식별해야 하며 그렇지 못하면 대기한다.
- 완료 근거는 현재 선택/알람 카드/지도 도착 화면/송신 상태/메일 상세의 비민감 신호다. 가린 행, 위험 동작, 임의 OCR 본문은 후보에 추가하지 않는다.

## 오류 및 보류

미지원 화면/낮은 확신/동일 위치 후보 충돌 시 no_target 또는 unknown.

## 구현 완료 기준

디스플레이 메뉴와 시간 제한 목록, 알람 편집과 저장 카드에서 서로 다른 후보와 검증 신호가 나오는지 확인.

## 호출 조건과 책임 경계

- **호출 시점** 로컬 정규화 프레임 준비.
- **호출자 또는 입력 작성자** N-08 화면과 사전 검증된 앱 프로필.
- **책임 경계** 안전한 대상만 찾는다. 타깃 ID, 관찰 근거 및 로컬 좌표를 분리.

## 상세 입출력 계약

아래 필드는 노드별 입력과 `NodeResult.data`의 타입이다. 공통 반환과 버전·오류 필드는 [결과 계약](../node-result-contract.md)을 따른다. 표의 키는 모두 선언하고, null 허용 필드에 값이 없으면 null을 넣는다. `Local*` 및 `VolatileText` 값은 지정된 처리 경계에서만 쓰며 상태 투영, 재연결 응답, 진단 로그에 복사하지 않는다.

### 입력

| 필드 | 타입 | null 허용 |
|---|---|---|
| `local_frame` | `LocalFrame` | 불가 |
| `profile_id` | `str` | 불가 |
| `profile_revision` | `int` | 불가 |
| `screen_hint` | `str` | 가능 |

### 결과 데이터

| 필드 | 타입 | null 허용 |
|---|---|---|
| `screen_kind` | `enum` | 불가 |
| `targets` | `LocalTarget[]` | 불가 |
| `verified_signals` | `enum[]` | 불가 |
| `coverage` | `enum` | 불가 |
| `frame_health` | `enum` | 불가 |

현재 보이는 버튼과 아래쪽 후보의 단서를 분리한다. 보이지 않는 label만으로 아래에 있다고 반환하지 않는다. coverage는 검사를 끝냈는지를 나타낸다. targets 배열이 비어도 observation_partial이 가능하다. LocalTarget 좌표는 부모 기기에만 존재한다.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `targets_found` | 모든 필요한 경로가 끝났고 대상 확인 | 좌표는 로컬에. 식별자만 상태에 전달 |
| `success` | `no_targets` | 정상 분류·검사 완료, 보이는 대상 0건 | 빈 배열, 도착·부재의 증거로 쓰지 않음 |
| `partial` | `observation_partial` | 일부 검출기 실패, 독립 단서는 유효 | 가용 결과 0건도 허용. no_targets 아님 |
| `error` | `null` | 프로필 불일치·필수 처리 모두 실패 | 비교·도착·표시 판단 중단 |
