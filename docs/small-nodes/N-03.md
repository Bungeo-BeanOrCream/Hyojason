# N-03 · start_or_close_call

- **위치와 담당** B · Android/RTC/서버
- **상위 노드** [B-01](../big-nodes/B-01.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

부모 발신·자녀 수신과 RTC 연결, 오디오 출력, RTC 종료 흐름만 관리한다.

| 경계 | 계약 |
|---|---|
| 입력 | 승인된 페어, 발신/수락/끊기, RTC room 참가·연결, 오디오 장치 |
| 출력 | CallState와 call_id, 양쪽 역할의 연결 여부, 종료 사유 |

## 처리 규칙

- 부모 발신→자녀 화면 초대→수락 후 역할별 단기 RTC 토큰→두 사람의 트랙 확인. P0 수신 화면은 개발 앱이 열려 있다고 가정한다.
- 가시 Activity에서 녹음 권한 및 배경 통화에 필요한 서비스 유형을 준비한다. 화면만 전환해도 연결이 유지되는지 검증한다.
- 안내 시작 때 이어폰이나 Bluetooth가 연결돼 있으면 기존 라우팅을 존중한다. 그 외 스피커폰으로 전환을 시도한다.
- 종료는 RTC만 연결 해제하고 call.ended를 보낸다. 제어 채널·도움 완료는 별도의 상태머신에 맡긴다.

## 오류 및 보류

재수락은 새 방을 만들지 않음. 오디오 차단, 수신 타임아웃, 참가 실패를 구별하고 로컬 세션을 복구한다.

## 구현 완료 기준

양쪽 AVD가 교대로 말하며 부모가 Settings 전환, 자녀 끊기 뒤 부모는 다른 앱을 계속 쓰는지 확인.
