# N-15 · interpret_child_turn

- **위치와 담당** Agent 서버 · C
- **상위 노드** [B-05](../big-nodes/B-05.md)
- **상태** 계약 확정. 구현 및 실험 전.

확정 발화에서 버튼 지시를 분리하고, 통화 중 대화 전체로 Zoro-1이 추정한 목표 확률을 갱신한다.

## 호출 조건

현재 통화(CALL_CHILD_LED)의 최신 speech.final마다. 목표 추정은 두 역할의 확정 발화 모두, 버튼 지시 해석은 자녀 트랙 발화만 대상으로 한다.

## 입출력 계약

다음 표는 노드 입력과 `NodeResult.data`의 필수 키다. [공통 결과와 Diagnostic](../node-result-contract.md)을 적용한다.

### 입력

| 필드 | 타입 | null |
|---|---|---|
| `speech` | `FinalUtterance` | 불가 |
| `recent_utterances` | `FinalUtterance[]` | 불가 |
| `existing_goal` | `Goal` | 허용 |
| `goal_belief` | `GoalBelief` | 허용 |
| `goal_catalog_revision` | `int` | 불가 |
| `basis` | `Basis` | 불가 |

`recent_utterances`는 현재 도움의 최근 확정 발화 창이다(두 역할, `speech` 포함, 최대 10개 초기값). 텍스트는 휘발성으로만 쓰고 저장하지 않는다. `goal_belief`는 N-11이 보관한 직전 목표 확률이다.

- 지시 초안과 목표 초안은 B-05가 N-11에 별도 전송한다. 유효 지시 초안은 목표 모델 응답을 기다리지 않는다. 최종 결과는 진단용이며 이미 전달한 초안을 반복 적용하지 않는다.
- 짧은 버튼 지시는 한 행동·라벨 하나를 잠정 표현한다. 등록된 동의어나 ‘그 버튼’처럼 모호한 라벨은 N-27에서 화면 옵션 또는 UNKNOWN에 매핑한다.
- 목표는 키워드로 미리 거르지 않는다. 확정 발화마다 Zoro-1이 최근 대화 창 전체를 보고 지원 목표 카탈로그 전체와 NONE에 대한 확률을 낸다. 이 분포가 그 시점의 목표 확률(GoalBelief)이며 직전 확률을 대체한다.
- 확률 1위 목표가 채택 기준(1위 0.70 이상, 2위와 차이 0.15 이상)을 넘으면 그 목표를 현재 목표로 설정한다. 1위가 기존 목표와 다르면 대화 중 목표가 바뀐 것으로 보고 새 목표 초안을 보낸다. 같은 목표·슬롯은 revision을 늘리지 않는다.
- 기준에 못 미치거나 1위가 NONE이면 기존 목표를 지우지 않고 유지한다. 잡담 한 마디로 목표가 흔들리지 않게 하기 위함이다.
- 슬롯 값은 모델이 만들지 않는다. 채택된 목표의 카탈로그 규칙으로 최근 대화 창에서 채우고, 필수 슬롯이 없으면 확률만 갱신하고 목표 초안은 보내지 않는다.
- 분명한 새 버튼 지시이면 새 revision으로 이전 것을 종료한다. 지시 아닌 말, 부모 발화, 중간 전사는 기존 지시를 변경하지 않는다. 부모 발화는 목표 확률만 갱신할 수 있다. 여러 단계를 자동으로 큐잉하지 않는다.

## 반환 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `instruction_ready` | 한 개 자녀 행동 인식, 목표 여부는 독립 | N-11 지시 채택 및 필요 시 목표 업데이트 |
| `success` | `goal_only` | 확률 1위 목표가 기준을 넘고 슬롯 유효, 버튼 지시 없음 | 목표 설정 또는 변경만, 통화 중 표시 예약 없음 |
| `success` | `waiting` | 모호·목표 없음·잡담, 지시의 필요 조건 미충족 | 목표 확률만 갱신하고 대기. 새 지시임이 확실할 때만 이전 표시 무효화 |
| `success` | `policy_denied` | 지시가 금지 위험 범위 | 조작 지시 폐기, 보호 문구만 |
| `partial` | `instruction_only` | 유효 지시는 있으나 별도의 목표 추론/필수 슬롯 실패 | 지시만 써서 개입 가능, 실패한 목표로 인계 금지 |
| `error` | `null` | 이전 자녀 utterance_seq 또는 처리 필수 단계 실패 | 검증된 초안이 전혀 없는 경우에만 error. 별개 지시가 검증됐으면 partial |
