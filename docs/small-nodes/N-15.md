# N-15 · infer_goal_or_change

- **위치와 담당** C · Agent 서버
- **상위 노드** [B-05](../big-nodes/B-05.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

대화에서 단일 목표·세부 조건을 정하고 기존 목표의 변경 여부를 선택한다.

| 경계 | 계약 |
|---|---|
| 입력 | 확정 발화와 역할·순서, 승인된 goal 목록, 현재 목적과 슬롯 |
| 출력 | GoalResolution(goal_id, slots, changed, source_utterance_id, confidence) |

## 처리 규칙

- 목표가 없으면 지원 목표와 NONE 중 선택한다. 활성 중에는 우선 CHANGE 또는 KEEP 판단. 변경 또는 슬롯 정정이면 새 후보를 확정한다.
- 허용 목표 슬롯은 선택 범위와 타입을 정한다. TIMEOUT 예시는 10분, ALARM은 날짜 의미와 시각, MAP은 확인 가능한 목적지다. 발화 근거 없이 날짜나 의미를 만들어 넣지 않는다.
- 모호한 정정은 보류하고 기존 안내를 잠시 치운다. 유효한 변경 승인 뒤 새 revision을 발행한다. 명확한 목적은 확인 질문 없이 안내한다.

## 오류 및 보류

정정 발화의 구버전 결과는 폐기. 앨범 공유 같은 지원 밖 목표는 NONE으로 분류하고 안내 표시는 P1.

## 구현 완료 기준

SET_FONT→SET_TIMEOUT 10분, 오전/오후 정정, '아니...'만 나온 경우, 지원 목록 외 입력을 각각 확인.
