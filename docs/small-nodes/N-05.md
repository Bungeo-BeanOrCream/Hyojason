# N-05 · transcribe_korean_turn

- **위치와 담당** B · STT
- **상위 노드** [B-02](../big-nodes/B-02.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

역할별 오디오에서 한국어 발화의 부분·확정 응답을 만든다.

| 경계 | 계약 |
|---|---|
| 입력 | 승인된 AudioChunk, 기존 turn_id, STT 가용 상태 |
| 출력 | TranscriptPartial/TranscriptFinal(text, speaker_role, ended_at, reliability) |

## 처리 규칙

- 짧은 무음 기준의 endpointing을 첫 구성에서 검증한다. 부분 응답은 타이핑 상태 정도에만 사용한다.
- 정정 의미가 바뀌는 문장을 자르지 않도록 앞뒤 연결을 유지한다. 시각·숫자·오전오후가 잘못 인식되는 사례를 포함한다.
- 소음·겹침·인식 실패를 낮은 신뢰도로 구분하고, 오디오 원본을 성공/실패 디버그 로그에 남기지 않는다.

## 오류 및 보류

STT timeout·단말 마이크 미입력·무언 구간을 분리한다. 실제 시연에서 대체 텍스트는 별도 provenance.

## 구현 완료 기준

'내일 아침 6시'와 '아니, 화면 꺼지는 거부터'를 실제 음성으로 받아 안정된 최종 문장을 전달.
