# N-05 · transcribe_korean_turn

- **위치와 담당** B · STT
- **상위 노드** [B-02](../big-nodes/B-02.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

역할별 오디오에서 한국어 발화의 부분·확정 응답을 만든다.

| 경계 | 계약 |
|---|---|
| 입력 | 승인된 AudioChunk, 기존 turn_id, STT 가용 상태 |
| 출력 | TranscriptPartial/TranscriptFinal(text, speaker_role, ended_at, reliability) |

## 처리 규칙

- 짧은 무음 기준의 endpointing을 첫 구성에서 검증한다. 부분 응답은 타이핑 상태 정도에만 사용한다.
- 정정 의미가 바뀌는 문장을 자르지 않도록 앞뒤 연결을 유지한다. 시각·숫자·오전오후가 잘못 인식되는 사례를 포함한다.
- 소음·겹침·인식 실패를 낮은 신뢰도로 구분하고, 오디오 원본을 성공/실패 디버그 로그에 남기지 않는다.

## 오류 및 보류

STT timeout·단말 마이크 미입력·무언 구간을 분리한다. 실제 시연에서 대체 텍스트는 별도 provenance.

## 구현 완료 기준

'내일 아침 6시'와 '아니, 화면 꺼지는 거부터'를 실제 음성으로 받아 안정된 최종 문장을 전달.

## 호출 조건과 책임 경계

- **호출 시점** 역할별 오디오가 들어오거나 발화 끝 감지.
- **호출자 또는 입력 작성자** N-04의 검증된 로컬 오디오.
- **책임 경계** 텍스트 인식만 수행. 목표/명령 판단은 N-15.

## 상세 입출력 계약

아래 필드는 노드별 입력과 `NodeResult.data`의 타입이다. 공통 반환과 버전·오류 필드는 [결과 계약](../node-result-contract.md)을 따른다. 표의 키는 모두 선언하고, null 허용 필드에 값이 없으면 null을 넣는다. `Local*` 및 `VolatileText` 값은 지정된 처리 경계에서만 쓰며 상태 투영, 재연결 응답, 진단 로그에 복사하지 않는다.

### 입력

| 필드 | 타입 | null 허용 |
|---|---|---|
| `window_ref` | `LocalRef` | 불가 |
| `speaker_role` | `enum` | 불가 |
| `call_id` | `str` | 불가 |
| `turn_id` | `str` | 불가 |
| `stt_deadline_ms` | `int` | 불가 |

### 결과 데이터

| 필드 | 타입 | null 허용 |
|---|---|---|
| `turn_id` | `str` | 불가 |
| `speaker_role` | `enum` | 불가 |
| `finality` | `enum` | 불가 |
| `ended_at` | `Timestamp` | 가능 |
| `text` | `VolatileText` | 가능 |
| `reliability` | `enum` | 불가 |

중간 전사에도 turn_id와 speaker_role을 유지한다. 확정 텍스트는 N-06에만 전달한다.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `transcribed` | 음성 구간이 정상 종료되고 확정 인식 | 확정만 N-06으로 전달 |
| `success` | `no_speech` | 정상 무언 구간 | 업무 추론을 호출하지 않음 |
| `partial` | `transcript_uncertain` | 소음·겹침 때문에 일부 단어만 유효 | 목표 확정 단계로 보내지 않고 대기 |
| `error` | `null` | STT 실패·타임아웃 또는 음성 수신 불가 | 업무상 무언으로 바꾸지 않음 |
