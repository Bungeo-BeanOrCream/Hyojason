# N-07 · open_or_close_projection

- **위치와 담당** A · Android
- **상위 노드** [B-03](../big-nodes/B-03.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

부모 화면 캡처를 승인 이후 시작하고 시스템 종료에서 정리한다.

| 경계 | 계약 |
|---|---|
| 입력 | Android MediaProjection 동의 결과, 앱별 화면/전체 화면 선택, help state |
| 출력 | projection_epoch, memory-only frame source, capture state |

## 처리 규칙

- 도움 시작 전의 온보딩에서 권한 설명을 하고 활성 세션에서 캡처를 연다. API 요구대로 서비스·콜백 설정을 확인한다.
- 온보딩에서 설정한 화면 공유 허용과 실제 승인 토큰을 분리한다. epoch는 새 승인 때마다 발급한다.
- 통화 종료 자체는 활성 도움의 projection을 정지하지 않는다. 도움 종료, 권한 철회, onStop에서는 입력과 파싱 큐·좌표를 정리한다.

## 오류 및 보류

캡처 거절, 보호된 영상, 시스템 중단에서 자동 Overlay를 제거하고 재승인을 기다린다.

## 구현 완료 기준

캡처 시작→통화 종료→Clock 전환→시스템 중지에서 프레임 유지와 중단을 순서대로 검증.

## 호출 조건과 책임 경계

- **호출 시점** 부모 동의, 캡처 승인, 정지 콜백.
- **호출자 또는 입력 작성자** 부모 Android의 사용자가 승인한 MediaProjection 이벤트.
- **책임 경계** 새 동의의 캡처만 연다. RTC 종료는 그 자체로 캡처 중단 조건 아님.

## 상세 입출력 계약

아래 필드는 노드별 입력과 `NodeResult.data`의 타입이다. 공통 반환과 버전·오류 필드는 [결과 계약](../node-result-contract.md)을 따른다. 표의 키는 모두 선언하고, null 허용 필드에 값이 없으면 null을 넣는다. `Local*` 및 `VolatileText` 값은 지정된 처리 경계에서만 쓰며 상태 투영, 재연결 응답, 진단 로그에 복사하지 않는다.

### 입력

| 필드 | 타입 | null 허용 |
|---|---|---|
| `help_id` | `str` | 불가 |
| `operation` | `enum` | 불가 |
| `approval_ref` | `LocalRef` | 가능 |
| `projection_epoch` | `str` | 가능 |
| `service_state` | `enum` | 불가 |

### 결과 데이터

| 필드 | 타입 | null 허용 |
|---|---|---|
| `projection_epoch` | `str` | 가능 |
| `capture_state` | `enum` | 불가 |
| `frame_source` | `LocalRef` | 가능 |

system approval은 projection_epoch 하나에만 사용한다. 재시작은 새 사용자 승인과 새 epoch를 사용한다.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `capture_started` | 새 승인과 서비스 조건 충족 | 새 epoch, N-08 열기 |
| `success` | `capture_stopped` | 시스템 중지 또는 사용자 정지 | 프레임·좌표 정리, Overlay 즉시 내림 |
| `success` | `capture_denied` | 사용자가 캡처를 거절 | 가이드를 보류하고 재승인 기다림 |
| `error` | `null` | 기존 승인 재사용·FGS 초기화 실패 | 예전 캡처 재개 금지 |
