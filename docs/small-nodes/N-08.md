# N-08 · prepare_frame_for_detection

- **위치와 담당** A · Android
- **상위 노드** [B-03](../big-nodes/B-03.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

프레임을 현지 분석 가능한 화면으로 준비하며 원본 수명과 좌표 변환을 제한한다.

| 경계 | 계약 |
|---|---|
| 입력 | 이미지 버퍼·시간·크기·회전, window bounds와 inset, 자기 Overlay 영역 |
| 출력 | LocalFrame(flags, viewport, layout_revision, monotonic_time), 공백 신호 |

## 처리 규칙

- 원본을 파일에 쓰지 않고 처리 후 닫는다. 프레임이 밀리면 최신 것만 처리한다.
- 회전/화면 키보드/inset 변화를 본다. 자기 빨간 표시나 상단 띠가 캡처에 들어오면 검출 영역에서 제외한다.
- 잠금·권한·OTP·보호 가능한 화면을 저비용으로 먼저 분류한다. 인식·로그에는 보호된 내용 대신 공백 코드만 남긴다.

## 오류 및 보류

빈 프레임·UV 차이·예상 화면 잘림에 기존 위치를 쓰지 않는다.

## 구현 완료 기준

키보드를 열고 글자 크기를 바꿔도 다음 frame layout만 사용하고 작업 상태에 원본이 남지 않는지 확인.

## 호출 조건과 책임 경계

- **호출 시점** 승인된 epoch에서 프레임 수신.
- **호출자 또는 입력 작성자** N-07의 로컬 프레임 스트림.
- **책임 경계** 화면 정규화와 보호 화면 사전 검사. 원시 이미지·좌표는 로컬만 사용.

## 상세 입출력 계약

아래 필드는 노드별 입력과 `NodeResult.data`의 타입이다. 공통 반환과 버전·오류 필드는 [결과 계약](../node-result-contract.md)을 따른다. 표의 키는 모두 선언하고, null 허용 필드에 값이 없으면 null을 넣는다. `Local*` 및 `VolatileText` 값은 지정된 처리 경계에서만 쓰며 상태 투영, 재연결 응답, 진단 로그에 복사하지 않는다.

### 입력

| 필드 | 타입 | null 허용 |
|---|---|---|
| `projection_epoch` | `str` | 불가 |
| `frame_ref` | `LocalRef` | 불가 |
| `captured_mono_ms` | `int` | 불가 |
| `bounds` | `Rect` | 불가 |
| `rotation` | `int` | 불가 |
| `overlay_masks` | `Rect[]` | 불가 |

### 결과 데이터

| 필드 | 타입 | null 허용 |
|---|---|---|
| `frame_ref` | `LocalRef` | 가능 |
| `viewport` | `Rect` | 가능 |
| `layout_revision` | `int` | 불가 |
| `frame_health` | `enum` | 불가 |
| `captured_mono_ms` | `int` | 불가 |

frame_ref는 프로세스 내부 소유권 참조다. 회전·viewport가 달라지면 layout_revision을 증가시킨다.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `frame_ready` | 최신 승인과 정상 프레임 | N-09으로 로컬 전달 |
| `success` | `protected_screen` | 시스템 보호·권한 UI 감지 | 원본 폐기, 공백 신호와 표시 제거 |
| `partial` | `geometry_uncertain` | 이미지는 유효하나 viewport나 inset 불명확 | 좌표 없는 부분 상태만, 렌더 금지 |
| `error` | `null` | 새 epoch와 프레임 불일치 또는 정규화 불가능 | 기존 좌표 폐기 |
