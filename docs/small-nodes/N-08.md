# N-08 · prepare_frame_for_detection

- **위치와 담당** A · Android
- **상위 노드** [B-03](../big-nodes/B-03.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

프레임을 현지 분석 가능한 화면으로 준비하며 원본 수명과 좌표 변환을 제한한다.

| 경계 | 계약 |
|---|---|
| 입력 | 이미지 버퍼·시간·크기·회전, window bounds와 inset, 자기 Overlay 영역 |
| 출력 | LocalFrame(flags, viewport, layout_revision, monotonic_time), 공백 신호 |

## 처리 규칙

- 원본을 파일에 쓰지 않고 처리 후 닫는다. 프레임이 밀리면 최신 것만 처리한다.
- 회전/화면 키보드/inset 변화를 본다. 자기 빨간 표시나 상단 띠가 캡처에 들어오면 검출 영역에서 제외한다.
- 잠금·권한·OTP·보호 가능한 화면을 저비용으로 먼저 분류한다. 인식·로그에는 보호된 내용 대신 공백 코드만 남긴다.

## 오류 및 보류

빈 프레임·UV 차이·예상 화면 잘림에 기존 위치를 쓰지 않는다.
