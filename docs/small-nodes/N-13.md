# N-13 · reconcile_reconnect

- **위치와 담당** D · 서버/클라이언트
- **상위 노드** [B-04](../big-nodes/B-04.md)
- **상태** [재접속 복원 구현](../../server/session/hyojason_session/reconnect.py). [FIXTURE 단위 테스트](../../server/session/tests/test_n13_reconcile_reconnect.py)와 [N-11 연동 테스트](../../server/session/tests/test_session_control.py)에서 13.1~13.4를 재현한다. 클라이언트 쪽 규칙은 [참조 구현](../../server/session/hyojason_session/client_resume_gate.py)으로 두고, 앱 이식과 실제 AVD 재접속 검증은 후속 통합에서 진행한다.

제어 채널 재접속에서 최신 상태와 필요한 재검증만 복원한다.

| 경계 | 계약 |
|---|---|
| 입력 | 인증된 역할, pair_id/help_id, 신규 연결, 마지막 event_seq |
| 출력 | 역할별 snapshot 또는 ended/unknown, 재관찰 요청 |

## 처리 규칙

- 과거 명령은 재생하지 않고 최신 목표와 도움 상태를 응답한다. 자녀 화면에는 부모 화면 후보가 포함되지 않는다.
- 부모가 다시 접속하면 직전 Overlay·타이머를 제거하고 최신 관찰부터 선택을 다시 요청한다.
- 서버가 재시작했다면 복구 가능한 도움과 존재하지 않는 도움을 구분한다. 후자에 대한 오래된 가이드를 적용하지 않는다.

## 오류 및 보류

부모가 일시정지하면 재접속이 승인 상태를 자동으로 켜지 않는다. 토큰·역할 오류는 연결 종료.

## 구현 완료 기준

오프라인 동안 goal이 1→2가 되면 늦은 명령을 무시하고 관찰·좌표가 새로 확인된 뒤만 표시.

## 호출 조건과 책임 경계

- **호출 시점** 부모 또는 자녀 제어 채널 재접속.
- **호출자 또는 입력 작성자** 인증된 최신 snapshot 조회·마지막 수신 이벤트 참조.
- **책임 경계** 최신 권위 상태만 복구. 지나간 Overlay 명령 재생 금지.

## 상세 입출력 계약

아래 필드는 노드별 입력과 `NodeResult.data`의 타입이다. 공통 반환과 버전·오류 필드는 [결과 계약](../node-result-contract.md)을 따른다. 표의 키는 모두 선언하고, null 허용 필드에 값이 없으면 null을 넣는다. `Local*` 및 `VolatileText` 값은 지정된 처리 경계에서만 쓰며 상태 투영, 재연결 응답, 진단 로그에 복사하지 않는다.

### 입력

| 필드 | 타입 | null 허용 |
|---|---|---|
| `pair_id` | `str` | 불가 |
| `help_id` | `str` | 가능 |
| `role` | `enum` | 불가 |
| `last_event_seq` | `int` | 불가 |
| `snapshot_request_id` | `str` | 불가 |

### 결과 데이터

| 필드 | 타입 | null 허용 |
|---|---|---|
| `snapshot` | `RoleSnapshot` | 가능 |
| `server_event_seq` | `int` | 불가 |
| `must_reobserve` | `bool` | 불가 |
| `resume_state` | `enum` | 불가 |

권한을 적용한 RoleSnapshot을 새로 생성한다. reconnect 뒤 부모 reobserve가 끝나기 전에는 전에 있던 GuideProposal을 재사용하지 않는다.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `snapshot_ready` | 동일 도움·정상 역할로 재접속 | 부모 역할만 목표/허용 지시 상태. 자녀는 도착/완료 범위만 제공. 부모는 재관찰 |
| `success` | `no_active_help` | 도움이 끝났거나 서버 재시작으로 상태 없음 | 로컬 안내·캐시 제거 |
| `error` | `null` | 권한·토큰·역할 불일치 | snapshot 제공 금지 |
