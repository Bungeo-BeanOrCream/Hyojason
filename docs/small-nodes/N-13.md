# N-13 · reconcile_reconnect

- **위치와 담당** D · 서버/클라이언트
- **상위 노드** [B-04](../big-nodes/B-04.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

제어 채널 재접속에서 최신 상태와 필요한 재검증만 복원한다.

| 경계 | 계약 |
|---|---|
| 입력 | 인증된 역할, pair_id/help_id, 신규 연결, 마지막 event_seq |
| 출력 | 역할별 snapshot 또는 ended/unknown, 재관찰 요청 |

## 처리 규칙

- 과거 명령은 재생하지 않고 최신 목표와 도움 상태를 응답한다. 자녀 화면에는 부모 화면 후보가 포함되지 않는다.
- 부모가 다시 접속하면 직전 Overlay·타이머를 제거하고 최신 관찰부터 선택을 다시 요청한다.
- 서버가 재시작했다면 복구 가능한 도움과 존재하지 않는 도움을 구분한다. 후자에 대한 오래된 가이드를 적용하지 않는다.

## 오류 및 보류

부모가 일시정지하면 재접속이 승인 상태를 자동으로 켜지 않는다. 토큰·역할 오류는 연결 종료.

## 구현 완료 기준

오프라인 동안 goal이 1→2가 되면 늦은 명령을 무시하고 관찰·좌표가 새로 확인된 뒤만 표시.
