# N-04 · ingest_participant_audio

- **위치와 담당** B · RTC 수신 서버
- **상위 노드** [B-02](../big-nodes/B-02.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

실제 승인 대상의 RTC 마이크 트랙만 역할별 STT 입력으로 제한한다.

| 경계 | 계약 |
|---|---|
| 입력 | RTC 참가자/트랙 정보, 서버 발급 역할 매핑, active call/consent |
| 출력 | 역할별 휘발성 AudioChunk 또는 dropped 입력 |

## 처리 규칙

- 토큰의 identity를 서버가 발급한 역할과 대조한다. 하나의 마이크 트랙만 승인하며 화면·영상·다른 참가자 트랙을 무시한다.
- 오디오 큐는 역할과 call_id 별로 격리한다. 처리가 밀리면 오래된 구간을 버리고 상태를 알린다.
- 통화 종료/철회에서 구독을 끊고 레이스로 도착한 바이트를 폐기한다. 원본을 파일이나 라이브러리 로그에 쓰지 않는다.

## 오류 및 보류

다른 통화/참가자 입력은 거절. 단말 소리가 동일하면 테스트 오디오 라우팅 문제로 표기한다.

## 구현 완료 기준

다른 역할의 말과 원본 스피커 에코가 명령으로 중복 입력되지 않는지 실제 마이크에서 확인.

## 호출 조건과 책임 경계

- **호출 시점** 승인된 통화의 오디오가 도착.
- **호출자 또는 입력 작성자** LiveKit의 참가자 트랙과 N-03 ACTIVE 상태.
- **책임 경계** 역할별 마이크 입력만 제공. 원본을 서버 또는 파일에 영속화하지 않음.

## 상세 입출력 계약

아래 필드는 노드별 입력과 `NodeResult.data`의 타입이다. 공통 반환과 버전·오류 필드는 [결과 계약](../node-result-contract.md)을 따른다. 표의 키는 모두 선언하고, null 허용 필드에 값이 없으면 null을 넣는다. `Local*` 및 `VolatileText` 값은 지정된 처리 경계에서만 쓰며 상태 투영, 재연결 응답, 진단 로그에 복사하지 않는다.

### 입력

| 필드 | 타입 | null 허용 |
|---|---|---|
| `call_id` | `str` | 불가 |
| `track_id` | `str` | 불가 |
| `participant_id` | `str` | 불가 |
| `source_kind` | `enum` | 불가 |
| `pcm` | `LocalBuffer` | 불가 |
| `chunk_seq` | `int` | 불가 |

### 결과 데이터

| 필드 | 타입 | null 허용 |
|---|---|---|
| `speaker_role` | `enum` | 가능 |
| `chunk_seq` | `int` | 불가 |
| `window_ref` | `LocalRef` | 가능 |
| `dropped_count` | `int` | 불가 |

track_id의 발화 역할을 검증한 뒤 로컬 STT 버퍼에 넣는다. pcm과 window_ref는 진단 및 네트워크 출력에 사용하지 않는다.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `audio_ready` | 유효 역할의 최신 마이크 트랙 | N-05 입력으로만 제한적으로 전달 |
| `success` | `ignored_input` | 영상·이미 철회된 트랙·중복 버퍼 | 큐에 적재하지 않고 폐기 |
| `partial` | `audio_gap` | 과부하로 일부 구간 폐기, 최신 버퍼는 정상 | 음절 결합 금지, 유효 최신 입력만 사용 |
| `error` | `null` | 타 페어 권한 위반 또는 입력 처리 불가 | 구독 중지, 원본 및 오류 메시지 제외 |

| 케이스 | 입력 또는 재현 조건 | 기대 결과 |
|---|---|---|
