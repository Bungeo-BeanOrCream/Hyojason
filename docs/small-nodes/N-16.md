# N-16 · enumerate_action_candidates

- **위치와 담당** Agent 서버 · C, 화면 프로필 A/D
- **상위 노드** [B-05](../big-nodes/B-05.md)
- **상태** 계약 확정. 구현 및 실험 전.

현 화면·아래·복귀 후보를 근거와 커버리지로 분류한다.

## 호출 조건

최신 안정 화면과 유효한 현재 지시/통화 후 목표가 있고, 해당 범위에서 위치 또는 경로 검사가 필요할 때.

## 입출력 계약

다음 표는 노드 입력과 `NodeResult.data`의 필수 키다. [공통 결과와 Diagnostic](../node-result-contract.md)을 적용한다.

- CALL_CHILD_LED에서 현재 지시의 label_key만 후보로 검색한다. 아래쪽은 현재 스크롤 가능 컨테이너와 검증된 프로필의 상대 순서 증거가 함께 있어야 한다. 현재 보이지 않는다는 이유만으로 아래라고 결론 내리지 않는다.
- CALL_CHILD_LED의 복귀 목적지는 지시 당시의 확인 화면이다. WRONG이 확인된 뒤에만 표시로 사용할 수 있다. POST_CALL_AGENT는 현재 목표까지 이어지는 등록 앱 프로필의 검증된 순방향 경로와 최근 방문에서 검증된 복귀 엣지를 탐색한다. 실제로 이전에 밟은 경로가 없어도 현재 화면의 검증된 직접 후보는 사용할 수 있다.
- 같은 projection_epoch 내 관찰된 방향과 reversibility를 검증한다. 공백을 넘지 않고 확인된 가장 짧은 경로, 가장 최근 관측, 안정 choice_id 순으로 정렬한다. P0 최근 보존 엣지 범위는 20개며 이 범위를 넘겨 근거가 끊기면 부분 검색이다.
- 부분 검색의 데이터는 가장 최신 화면에서 독립 검증한 직접 버튼만 사용한다. 스크롤과 복귀를 보류한다. 준비한 후보를 화면·모드·지시 버전이 바뀐 뒤 전달하지 않는다.

## 반환 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `candidates_found` | 필수 탐색 모두 종료, 유효 후보 존재 | 통화 중 N-27 후보 또는 검증 복귀 근거. 통화 후 N-17 후보 |
| `success` | `no_candidates` | 필수 탐색 완료, 후보 0개 | 빈 배열 반환. 모델 후보 선택을 생략 |
| `partial` | `search_incomplete` | 일부 탐색 실패/이력 공백, 다른 탐색은 완료 | 독립 직접 검증 후보만 사용. 0건이어도 no_candidates 아님 |
| `success` | `policy_denied` | 보호·금지 대상 | coverage=policy_blocked, 후보 0개, 표시하지 않음 |
| `error` | `null` | 유효 스코프/프로필 불일치 또는 탐색 전부 실패 | STALE_BASIS 또는 DEPENDENCY_UNAVAILABLE. 후보 생성 중단 |
