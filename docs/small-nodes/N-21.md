# N-21 · project_role_view

- **위치와 담당** D · 서버, B 자녀 UI
- **상위 노드** [B-07](../big-nodes/B-07.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

부모·자녀 화면에 각각 허용된 상태를 전달한다.

| 경계 | 계약 |
|---|---|
| 입력 | HelpSnapshot, actor_role, 최신 goal 및 arrival 결과 |
| 출력 | ParentView 또는 ChildView(goal, waiting, arrival, complete_available) |

## 처리 규칙

- 목표가 없으면 파악 중, 변경되면 동일 goal_revision 표시. 부모 상단 띠에는 통화 상대·목표·안내 끄기를 담는다.
- 자녀에는 최신 목표와 완료 가능 상태만 전달한다. 메일 본문, 부모 화면·좌표·전체 후보를 포함하지 않는다.
- RTC가 끝났어도 자녀 앱 첫 화면에 활성 도움의 목표와 도움 완료 버튼을 유지한다. 앱을 다시 열면 최신 상태 snapshot을 조회한다.

## 오류 및 보류

상태 공백은 확인 중으로 표시하고 최신 목표를 가장해 상세/원본을 표시하지 않는다.

## 구현 완료 기준

자녀 AVD가 통화 화면을 닫은 뒤 도착 알림을 확인하지만 부모 화면은 표시되지 않는다.
