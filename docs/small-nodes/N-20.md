# N-20 · render_parent_surfaces

- **위치와 담당** A · Android
- **상위 노드** [B-06](../big-nodes/B-06.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

부모 상단 띠와 실제 화면의 중복 없는 단계 안내를 표시한다.

| 경계 | 계약 |
|---|---|
| 입력 | 승인된 GuideDisplay, 상태 문구 및 상대 표시, Android Overlay 권한 |
| 출력 | 상단 띠 표시, 한 개 강조, 안내 끄기/통화 복귀 사용자 이벤트 |

## 처리 규칙

- TYPE_APPLICATION_OVERLAY를 좁은 영역으로 사용한다. 테두리 창에 FLAG_NOT_TOUCHABLE과 필요 시 FLAG_NOT_FOCUSABLE을 적용하더라도 터치 전달을 실제 버전에서 직접 확인한다.
- 큰 글씨, 대비, 한 안내만 적용한다. 상단 띠의 터치는 안내 끄기와 앱 복귀 버튼에만 할당하고 시스템·뒤의 앱을 가리지 않게 배치한다.
- 동의 철회, 화면 보호, 화면 공백, 앱 종료에는 즉시 모두 치운다. 도움 종료 상태에서 '다 됐어요!'는 자녀 완료인 경우 한 번만 표시한다.

## 오류 및 보류

차단 상태에서는 표시했다고 집계하지 않는다. 시스템 터치 보안이나 보호 화면을 변경하는 경로를 사용하지 않는다.

## 구현 완료 기준

Settings의 실제 대상과 Clock 알람 저장 터치가 진행되며 overlay permission 철회에서 안내가 사라지는지 시연 기기에서 확인.

## 호출 조건과 책임 경계

- **호출 시점** 표시 허용 결과, 최신 상태 변경 또는 부모 UI 조작.
- **호출자 또는 입력 작성자** N-19, N-21, N-23의 로컬 결과·이벤트.
- **책임 경계** 가이드와 띠를 표시·정리. 위험은 “되돌리기 어려운 동작이에요. 천천히 확인하세요”만 쓴다. 버튼 조작은 실제 사용자 터치.

## 상세 입출력 계약

아래 필드는 노드별 입력과 `NodeResult.data`의 타입이다. 공통 반환과 버전·오류 필드는 [결과 계약](../node-result-contract.md)을 따른다. 표의 키는 모두 선언하고, null 허용 필드에 값이 없으면 null을 넣는다. `Local*` 및 `VolatileText` 값은 지정된 처리 경계에서만 쓰며 상태 투영, 재연결 응답, 진단 로그에 복사하지 않는다.

### 입력

| 필드 | 타입 | null 허용 |
|---|---|---|
| `display` | `LocalGuide` | 가능 |
| `banner` | `ParentView` | 불가 |
| `operation` | `enum` | 불가 |
| `decision_id` | `str` | 가능 |
| `overlay_permission` | `bool` | 불가 |

### 결과 데이터

| 필드 | 타입 | null 허용 |
|---|---|---|
| `visible` | `bool` | 불가 |
| `visual_kind` | `enum` | 불가 |
| `decision_id` | `str` | 가능 |
| `user_event` | `enum` | 가능 |

N-20은 부모 손 조작을 막지 않는 하이라이트를 그린다. 승인된 중단 버튼 조작만 N-22로 전달하고 그 외 터치는 아래 앱에 통과한다.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `shown` | 실제 1개 대상 또는 대체 문구를 표시 | guide.shown, 터치 검사는 별도 |
| `success` | `cleared` | 표시 취소·종료를 정상 반영 | 가이드·타이머 없음 |
| `partial` | `banner_only` | 가이드 위치는 차단됐지만 띠는 안전 | 가이드 성공으로 집계하지 않음 |
| `error` | `null` | 시스템 표시 차단 또는 터치 실패 | 해당 창 제거, suppressed 보고 |
