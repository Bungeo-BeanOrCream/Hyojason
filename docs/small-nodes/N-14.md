# N-14 · call_zoro_decision

- **위치와 담당** C · 추론 adapter
- **상위 노드** [B-05](../big-nodes/B-05.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

선택형 Zoro-1 요청을 실제 모델에 보내고 확률·출력·버전 유효성을 검사한다.

| 경계 | 계약 |
|---|---|
| 입력 | 정해진 상태 필드, 질문 종류, 등록된 choice_id 목록, deadline |
| 출력 | DecisionResult(choice_id, probabilities, model_revision, latency_ms, reason) |

## 처리 규칙

- 가중치 접근을 선확인하고 checkpoint·decision head·보정 파일을 같은 revision으로 고정한다. 모델 카드에 배포한 버전의 직접 typed decision 호출을 따르고 실제 4종 질문을 smoke test한다.
- 질문별 ID와 선택지 순서를 생성해도 반환에서 ID로 대조한다. 확률 누락, 후보 외 출력, NaN, 비정상 범위 응답은 유효하지 않다.
- 짧은 요청 1회 기준으로 시작한다. 불필요한 긴 reasoning, 이미지 업로드, 프레임마다 호출은 기본 경로에 넣지 않는다. 추론 결과에는 실제 모델 ID와 revision을 표시한다.

## 오류 및 보류

시간 초과/서버 장애는 error, 응답은 맞지만 애매함은 success/hold. 한 번 새 상태에서 다시 요청할 수 있으나 지연 결과를 적용하지 않는다.

## 구현 완료 기준

각 결정 종류에서 실제 L40S/GPU endpoint 결과를 검증한다. 잘못된 choice_id 응답 주입 시 가이드 발행이 0건이다.
