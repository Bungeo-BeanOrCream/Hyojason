# N-25 · evaluate_end_to_end

- **위치와 담당** D · 리허설/통합, 전체 협업
- **상위 노드** [B-08](../big-nodes/B-08.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

실제 라이브와 모의 시험을 분리하고 요구사항의 통과 여부를 기록한다.

| 경계 | 계약 |
|---|---|
| 입력 | PRD 성공 기준, 고정 20개 발화와 A·B 리허설, 표시·판단 로그 |
| 출력 | V-01~V-07 결과와 실패 보고서, 실제/모의 구분 |

## 처리 규칙

- 시나리오별 목표·작업 성공·정정·도착 알림·최종 완료를 각각 기록한다. 한 항목만 통과한 실행을 완주로 세지 않는다.
- 3초 마감, 5초 목표 변경 반영, 확률·모델 revision 및 오류 코드를 실제로 측정한다. Zoro가 끊겼거나 시험 텍스트를 사용한 경로를 표시한다.
- 문제 화면 오류, 오래된 가이드, 가이드 터치, 네트워크 공백, 동의 철회를 검증한다. 테스트 계정 외의 오디오/화면 원본은 기록하지 않는다.

## 오류 및 보류

테스트 실패로 기능, 기기 또는 계약 중 어디가 확인되지 않았는지 구분한다. 보류와 오류를 성공으로 쓰지 않는다.

## 구현 완료 기준

A·B 각각 5회 및 20개 발화 결과표에 재현 순서와 기기·모델 버전이 남는다.
