# N-06 · finalize_instruction_turn

- **위치와 담당** B · 서버
- **상위 노드** [B-02](../big-nodes/B-02.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

중복·부분 발화·역순을 거르고 적용 가능한 문장만 publish한다.

| 경계 | 계약 |
|---|---|
| 입력 | 최종 STT, 발화 ID/순서, active call 및 최신 동의, 처리 중 turn |
| 출력 | speech.final 또는 ignored_partial / duplicate / stale / no_speech |

## 처리 규칙

- 동일 utterance_id의 최종 문장은 한 번만 수락한다. 역할·통화·절대시각 원본 대신 순서와 발화 종료를 함께 제공한다.
- '아니' 같은 불완전한 정정이 확인되면 대기 다루도록 알리고 목표는 새 최종 문장이 유효할 때 변경한다.
- 발화 종료 시점을 목표 변경 지연의 측정 시작점으로 보존하되 실제 원문은 공개 로그에서 제외한다.

## 오류 및 보류

동의 철회/RTC 종료 후 도착한 최종 응답을 폐기한다. 수동 입력은 source=manual_test.

## 구현 완료 기준

부분→확정→재전송→통화 종료 이후 누락 응답을 주입해 확정 1건만 downstream 수신.
