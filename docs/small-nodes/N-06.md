# N-06 · finalize_instruction_turn

- **위치와 담당** B · 서버
- **상위 노드** [B-02](../big-nodes/B-02.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

중복·부분 발화·역순을 거르고 적용 가능한 문장만 publish한다.

| 경계 | 계약 |
|---|---|
| 입력 | 최종 STT, 발화 ID/순서, active call 및 최신 동의, 처리 중 turn |
| 출력 | speech.final 또는 ignored_partial / duplicate / stale / no_speech |

## 처리 규칙

- 동일 utterance_id의 최종 문장은 한 번만 수락한다. 역할·통화·절대시각 원본 대신 순서와 발화 종료를 함께 제공한다.
- '아니' 같은 불완전한 정정이 확인되면 대기 다루도록 알리고 목표는 새 최종 문장이 유효할 때 변경한다.
- 발화 종료 시각을 발화 종료→t0 지연의 기준으로 보존한다. N-15의 지시 해석과 3초 게이트는 최신 자녀 확정 발화에서만 시작할 수 있다. N-15의 목표 확률 갱신은 두 역할의 확정 발화에서 실행한다. 부모 발화는 원문 로그·지시·타이머를 만들지 않는다.

## 오류 및 보류

동의 철회/RTC 종료 후 도착한 최종 응답을 폐기한다. 수동 입력은 source=manual_test.

## 구현 완료 기준

부분→확정→재전송→통화 종료 이후 누락 응답을 주입해 확정 1건만 downstream 수신.

## 호출 조건과 책임 경계

- **호출 시점** STT 부분·확정 결과 콜백.
- **호출자 또는 입력 작성자** N-05 결과와 최신 통화/동의.
- **책임 경계** 활성 통화의 확정 발화만 한 번 커밋. late 결과 차단.

## 상세 입출력 계약

아래 필드는 노드별 입력과 `NodeResult.data`의 타입이다. 공통 반환과 버전·오류 필드는 [결과 계약](../node-result-contract.md)을 따른다. 표의 키는 모두 선언하고, null 허용 필드에 값이 없으면 null을 넣는다. `Local*` 및 `VolatileText` 값은 지정된 처리 경계에서만 쓰며 상태 투영, 재연결 응답, 진단 로그에 복사하지 않는다.

### 입력

| 필드 | 타입 | null 허용 |
|---|---|---|
| `turn_id` | `str` | 불가 |
| `utterance_seq` | `int` | 불가 |
| `speaker_role` | `enum` | 불가 |
| `finality` | `enum` | 불가 |
| `text` | `VolatileText` | 가능 |
| `ended_at` | `Timestamp` | 가능 |

### 결과 데이터

| 필드 | 타입 | null 허용 |
|---|---|---|
| `utterance_id` | `str` | 가능 |
| `utterance_seq` | `int` | 불가 |
| `speaker_role` | `enum` | 불가 |
| `text` | `VolatileText` | 가능 |
| `triggered` | `bool` | 불가 |

utterance_id는 통화와 turn_id 안에서 유일하다. 중복은 같은 instruction을 다시 일으키지 않는다.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `final_committed` | 최신 활성 통화와 완성된 확정 문장 | speech.final 1회 발행. 두 역할 모두 N-15 목표 확률 갱신, 지시 해석은 자녀 역할만 |
| `success` | `partial_ignored` | 중간 인식만 들어옴 | 발행 없음 |
| `success` | `duplicate_ignored` | 같은 발화 ID·순서 재유입 | 기존 상태 유지 |
| `error` | `null` | 권한 철회, 통화 종료 후 결과, 이전 순서 | STALE_BASIS, 신규 목표 없음 |
