# N-19 · gate_guide_on_device

- **위치와 담당** A · Android
- **상위 노드** [B-06](../big-nodes/B-06.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

3초 타이머와 현재 화면 위치를 기준으로 실제 표시를 허용하거나 차단한다.

| 경계 | 계약 |
|---|---|
| 입력 | GuideProposal, 최신 로컬 좌표와 전체 revision, monotonic clock, 권한 및 띠 상태 |
| 출력 | GuideDisplay 또는 GuideSuppressed(reason, elapsed_ms) |

## 처리 규칙

- 새 의미 화면이나 목표가 확인되면 표시를 즉시 지우고 로컬 3초를 재시작한다. 시계가 3초에 닿기 전 제안을 준비할 수 있다.
- 현재 도움, 목표, 화면, projection 및 마지막 유효 프레임을 비교한다. layout이 바뀌면 최신 좌표의 유효성 확인 후에만 다시 렌더한다.
- 후보가 시간이 지나거나 권한을 잃으면 표시하지 않는다. 위치를 확인할 수 없는 BACK이나 홈 동작은 검증된 문구로만 표현할 수 있다.

## 오류 및 보류

만료, stale, overlay_blocked, frame_gap을 각각 분리한다. 늦게 도착한 결과는 그 사실을 기록한다.

## 구현 완료 기준

화면을 2초 후 다른 앱으로 바꾸면 첫 화면의 원은 뜨지 않고 다음 화면 기준으로 시간이 다시 흐른다.
