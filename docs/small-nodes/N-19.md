# N-19 · gate_guide_on_device

- **위치와 담당** 부모 Android · A
- **상위 노드** [B-06](../big-nodes/B-06.md)
- **상태** 계약 확정. 구현 및 실험 전.

단조 시계와 로컬 관찰로 3초 개입의 마지막 판정을 내린다.

## 호출 조건

지시 수신, 표시 제안, 관찰 변화, 로컬 마감, 모드/도움 전환 시.

## 입출력 계약

다음 표는 노드 입력과 `NodeResult.data`의 필수 키다. [공통 결과와 Diagnostic](../node-result-contract.md)을 적용한다.

### 입력

| 필드 | 타입 | null |
|---|---|---|
| `proposal` | `GuideProposal` | 허용 |
| `target` | `TargetDecision` | 허용 |
| `verdict` | `ActionVerdict` | 허용 |
| `local_observation` | `LocalObservation` | 허용 |
| `basis` | `Basis` | 불가 |
| `now_mono_ms` | `int` | 불가 |
| `t0_mono_ms` | `int` | 허용 |

### 결과 데이터

| 필드 | 타입 | null |
|---|---|---|
| `display` | `LocalGuide` | 허용 |
| `elapsed_ms` | `int` | 허용 |
| `reason` | `enum` | 불가 |
| `cancel_timer` | `bool` | 불가 |

## 고정 워크플로우

~~~mermaid
flowchart TD
    start(["N-19 호출"]) --> valid{"모드, 권한, 관련 Basis가 유효한가?"}
    valid -->|유효| prepare["최신 권한·Basis·프레임 및 진행 근거 재검사"]
    valid -->|무효| rejected["오류 또는 소속된 정책 결과"]
    prepare --> decide["3초, 지시 수행, 후속 표시 우선순위 적용"]
    decide --> checked{"표시를 안전하게 허용하는가?"}
    checked -->|확인| result["검증된 결과와 실행 근거"]
    checked -->|미확인| wait["명시적 보류·부분·오류 결과"]
    rejected --> envelope(["NodeResult"])
    result --> envelope
    wait --> envelope
~~~

- 통화 중 t0는 instruction.accepted 최초 적용. 통화 후 t0는 모드 전환 뒤 새 안정 의미 화면. 정확히 3,000ms에서 직전 또는 동시 입력 증거를 먼저 적용한다.
- 로컬 변화 감지 후 ActionVerdict가 늦으면 기다린다. 부모 발화나 좌표만 갱신되면 통화 중 타이머를 초기화하지 않는다.
- 정확한 조작은 테두리 0회, 3초 뒤 오선택은 검증 역경로 BACK, 아래쪽은 증거 있는 SCROLL_DOWN, 현재 버튼은 TAP. 중단·보호·위험·UNKNOWN은 [우선순위 계약](../instruction-policy.md)을 적용한다.

## 반환 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `waiting` | 시간 미도달, 증거 부족·정확한 판정 대기 | 표시하지 않음 |
| `success` | `followed` | 지시대로 조작한 결과 확인 | 표시 없이 현재 지시 닫기 또는 기존 표시 제거 |
| `success` | `intervene_tap` | 마감 뒤 입력 단서 없음 및 현재 대상 검증 | N-20에 로컬 테두리 요청 |
| `success` | `intervene_back` | 마감 뒤 WRONG과 역엣지 확인 | 뒤로 가기 안내 |
| `success` | `intervene_scroll` | 마감 뒤 입력 단서 없음 및 below_fold 검증 | 화면 내리기 안내 |
| `success` | `post_call_guide` | 통화 후 새 의미 화면 3초와 제안 모두 유효 | 현재 행동 하나 N-20에 전달 |
| `success` | `policy_denied` | 위험하거나 되돌리기 어려운 지시 | 보호 문구만 렌더 가능 |
| `error` | `null` | 무효 스코프, 권한 또는 로컬 유효성 실패 | 표시 제거 |
