# N-11 · reduce_help_state

- **위치와 담당** D · 제어 서버
- **상위 노드** [B-04](../big-nodes/B-04.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

통화/도움/관찰과 목표 revision을 단일 처리 경로로 갱신한다.

| 경계 | 계약 |
|---|---|
| 입력 | 인증된 call/consent/screen/utterance/goal/arrival/complete 이벤트 |
| 출력 | HelpSnapshot, state effects, duplicate / stale / rejected |

## 처리 규칙

- 도움 ID별 처리 직렬화. pair·역할·이벤트 ID를 확인하고 명령 순서를 검증한다.
- 목표/화면/권한 전이가 있으면 낮은 버전의 판단/도착 추정을 무효화한다. 현재 revision을 양쪽 화면에 공개한다.
- call.ended에서 OBSERVE만 유지할 수 있도록 두 축을 분리한다. 현재 유효 목표가 없으면 정리한다.

## 오류 및 보류

권한 실패·중복·이전 ID는 상태를 바꾸지 않는다. 동시 도착/완료가 있어도 최대 한 번 종료.

## 구현 완료 기준

goal 1→2 뒤 도착한 goal 1 가이드와 이미 종료된 도움의 완료 이벤트가 새 도움을 건드리지 않는다.
