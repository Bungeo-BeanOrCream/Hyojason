# N-24 · prepare_demo_fixtures

- **위치와 담당** D · AVD/자료
- **상위 노드** [B-08](../big-nodes/B-08.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

외부 네트워크와 기기 환경을 포함하여 5개 목표를 재현할 테스트 조건을 고정한다.

| 경계 | 계약 |
|---|---|
| 입력 | 두 AVD, 앱 버전, 역할·권한, 합성/테스트 자산 |
| 출력 | DemoFixtureList와 기기 상태, ready/blocked |

## 처리 규칙

- 동일 Android 버전과 한국어 UI를 맞추고 부모/자녀 앱 역할을 분리한다. 이어폰/스피커와 실제 마이크 경로를 확인한다.
- 설정값을 되돌릴 수 있도록 기록하고 Clock의 시간대·날짜, 지도 테스트 공개 장소, 메시지 상대 AVD 수신, Gmail 테스트 읽기 대상을 준비한다.
- 권한·로그인 화면은 본 시연 전 정리한다. 앱 버전, 화면 기준, 관찰 차단 여부를 시나리오별로 기록한다.

## 오류 및 보류

Android 제어 채널은 macOS 주소와 AVD 루프백을 구별한다. Gmail/지도 로그인이나 네트워크 실패를 앱 내부 성공으로 표기하지 않는다.

새 에뮬레이터 환경에서 앱 열기부터 A·B의 최소 목표를 문서에 따라 재현.
