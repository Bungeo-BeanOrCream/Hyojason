# N-18 · judge_goal_arrival

- **위치와 담당** C · Agent 서버, D 평가
- **상위 노드** [B-05](../big-nodes/B-05.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

목표에 도착했다고 추정할 수 있는지를 화면 근거와 모델 결정으로 판단한다.

| 경계 | 계약 |
|---|---|
| 입력 | 현재 목표·슬롯, 조작 전/후 화면과 목표별 verified_signals |
| 출력 | ArrivalDecision(arrived, confidence, evidence_key) 또는 not_arrived/hold |

## 처리 규칙

- 목표별 완료 증거를 먼저 확인한다. 편집 화면 진입만으로 저장됐다고 보지 않는다. 설정의 실제 선택값, 알람의 저장 및 예정 날짜 등 기대 기준과 대조한다.
- 단서가 확보되면 YES/NO를 실제 Zoro 함수로 판정한다. 이미 교체된 리비전, 미완료 증거, 낮은 확신에서는 도착 알림을 발행하지 않는다.
- 불확실한 도착 안내는 자녀에게 승인 버튼과 독립된 표시로 보낸다. 최종 완료는 N-22의 명시적 명령이 처리한다.

## 오류 및 보류

서버 응답 실패가 확정 완료로 이어지지 않는다. 화면이 다시 바뀌면 도착 결과를 무효화할 수 있다.

## 구현 완료 기준

맞는 알람 저장, 다른 시각 알람 저장, 저장되지 않은 편집 화면 세 상태를 구별한다.
