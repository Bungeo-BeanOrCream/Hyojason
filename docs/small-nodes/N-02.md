# N-02 · resolve_consent

- **위치와 담당** B · Android/서버
- **상위 노드** [B-01](../big-nodes/B-01.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

역할별 동의와 시스템 권한을 확인하여 음성 인식, 캡처와 표시가 가능한지 구분한다.

| 경계 | 계약 |
|---|---|
| 입력 | pair_id, call_id, 각 역할 동의·revision, 부모의 마이크·캡처·표시 허용 상태 |
| 출력 | ConsentView(agent_allowed, stt_allowed, capture_allowed, overlay_allowed, consent_revision) |

## 처리 규칙

- 통화에 참여한 것과 AI 처리에 동의한 것을 분리한다. 각 역할 동의 화면에 목적·범위를 쉽게 표시한다.
- 서버 동의는 서비스 동작을 허가하지만 Android 캡처·표시의 최종 권한은 로컬 확인값으로 판단한다.
- 철회·권한 잃음 이벤트는 미처리 음성/프레임/표시를 먼저 폐기하도록 전달한다. 통화만 계속할 수 있다.

## 오류 및 보류

한쪽만 동의하면 AI 유지 불가. 새 캡처에는 예전 승인 Intent를 재사용하지 않는다.

## 구현 완료 기준

자녀 동의 없음, 부모만 표시 거부, 통화 중 부모가 시스템 캡처 중지 등 3가지에서 해당 기능만 정리된다.

## 호출 조건과 책임 경계

- **호출 시점** 페어 확정·동의 변경·권한 철회.
- **호출자 또는 입력 작성자** N-01 결과, 양쪽 앱 consent.updated.
- **책임 경계** 서비스 내부 동의와 Android 권한을 분리하고 그 단계만 차단.

## 상세 입출력 계약

아래 필드는 노드별 입력과 `NodeResult.data`의 타입이다. 공통 반환과 버전·오류 필드는 [결과 계약](../node-result-contract.md)을 따른다. 표의 키는 모두 선언하고, null 허용 필드에 값이 없으면 null을 넣는다. `Local*` 및 `VolatileText` 값은 지정된 처리 경계에서만 쓰며 상태 투영, 재연결 응답, 진단 로그에 복사하지 않는다.

### 입력

| 필드 | 타입 | null 허용 |
|---|---|---|
| `pair_id` | `str` | 불가 |
| `call_id` | `str` | 가능 |
| `role` | `enum` | 불가 |
| `purpose` | `enum` | 불가 |
| `enabled` | `bool` | 불가 |
| `consent_revision` | `int` | 불가 |
| `device_capabilities` | `enum[]` | 불가 |

### 결과 데이터

| 필드 | 타입 | null 허용 |
|---|---|---|
| `agent_allowed` | `bool` | 불가 |
| `stt_allowed` | `bool` | 불가 |
| `capture_allowed` | `bool` | 불가 |
| `overlay_allowed` | `bool` | 불가 |
| `consent_revision` | `int` | 불가 |

agent_allowed는 양쪽 동의를 모두 마칠 때만 참이다. 캡처·표시 가능 여부는 부모 기기의 권한을 추가로 만족해야 한다.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `allowed` | 양쪽 AI 동의와 관련 권한이 유효 | 허가된 능력만 N-03/N-04/N-07에 전달 |
| `success` | `blocked` | 거절·철회 또는 권한 부족이 정상 관측됨 | 해당 기능 중지, 통화 정책은 독립 |
| `error` | `null` | 다른 페어 또는 비정상 버전·형식 | 무효 상태를 쓰지 않고 현재 동의 재조회 |

## 최소 검증과 기대 결과

| 케이스 | 입력 또는 재현 조건 | 기대 결과 |
|---|---|---|
| 02.1 | 양쪽 AI 동의와 관련 권한이 유효 | `success` / `allowed`. 허가된 능력만 N-03/N-04/N-07에 전달 |
| 02.2 | 거절·철회 또는 권한 부족이 정상 관측됨 | `success` / `blocked`. 해당 기능 중지, 통화 정책은 독립 |
