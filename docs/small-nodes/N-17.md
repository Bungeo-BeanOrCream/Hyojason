# N-17 · choose_single_guide

- **위치와 담당** C · Agent 서버
- **상위 노드** [B-05](../big-nodes/B-05.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

목표로 갈 다음 행동 하나를 골라 동작과 유효 범위를 제출한다.

| 경계 | 계약 |
|---|---|
| 입력 | 제공된 CandidateSet, 현재 화면·목표 revision, 비공개 구간 제외 요약 이력 |
| 출력 | GuideProposal 또는 WAIT/ASK_CHILD/suppressed |

## 처리 규칙

- 다음 한 행동의 옵션을 N-14로 보내고 현재 후보 목록·신뢰 기준으로 검증한다. Zoro가 좌표나 도구 실행을 만들어 반환할 자리를 두지 않는다.
- TAP, BACK, SCROLL_UP/DOWN, INPUT_HINT를 시연 P0로 처리한다. P1 슬라이더/길게 누르기는 기능을 켠 경우에만 후보에 추가한다.
- 현재 도움·목표·화면이 그대로일 때만 발행한다. 안내는 렌더러가 템플릿으로 바꾸고 이미 지나간 모델 옵션 수신은 제안 단계에서 폐기한다.

## 오류 및 보류

모델 실패·낮은 확신·금지는 각 사유 코드로 결과를 분리한다. 여러 행동을 동시에 반환하지 않는다.

## 구현 완료 기준

실제 화면에서 목표를 바꾸고 직전 모델 결과를 지연시켜 새 화면에는 최신 안내만 수신되는지 확인.
