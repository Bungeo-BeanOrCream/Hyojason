# N-22 · resolve_arrival_or_completion

- **위치와 담당** D · 제어 서버
- **상위 노드** [B-07](../big-nodes/B-07.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

도착 추정과 자녀 최종 완료, 부모 안내 끄기를 독립적으로 처리한다.

| 경계 | 계약 |
|---|---|
| 입력 | Zoro ArrivalDecision, 서버 상태, 도움 완료 또는 중단 요청 |
| 출력 | arrival.suspected/revoked, HelpEndRequested(reason), duplicate/stale result |

## 처리 규칙

- 현재 goal_revision과 부합하는 도착에서 알림을 한 번 발행한다. 증거가 무효가 되면 알림을 갱신한다.
- 인증된 자녀는 활성 도움에서 도착 알림 전에도 완료를 선택할 수 있다. 부모님 안내 끄기는 별도 종료 이벤트로 수락한다.
- 사용자 이벤트 대상 help_id/revision을 검증하고 동시·중복으로 두 번 종료되지 않도록 원자적으로 승인한다.

## 오류 및 보류

역할이 잘못된 요청, 다른 도움과 재연결 이전의 완료 신호, 구식 revision은 거절하고 현재 상태를 안내한다.

## 구현 완료 기준

도착 알림만 발생하면 도움 활성, 자녀 완료 버튼을 누르면 종료, 두 번 누른 경우 하나의 종료만 확인.

## 호출 조건과 책임 경계

- **호출 시점** 도착 판단 또는 자녀 완료·부모 중단 요청.
- **호출자 또는 입력 작성자** N-18 모델 판단, 역할별 제어 이벤트.
- **책임 경계** 도착 추정과 의도적 도움 끝내기를 분리. 종료 승인만 발행.

## 상세 입출력 계약

아래 필드는 노드별 입력과 `NodeResult.data`의 타입이다. 공통 반환과 버전·오류 필드는 [결과 계약](../node-result-contract.md)을 따른다. 표의 키는 모두 선언하고, null 허용 필드에 값이 없으면 null을 넣는다. `Local*` 및 `VolatileText` 값은 지정된 처리 경계에서만 쓰며 상태 투영, 재연결 응답, 진단 로그에 복사하지 않는다.

### 입력

| 필드 | 타입 | null 허용 |
|---|---|---|
| `arrival` | `ArrivalDecision` | 가능 |
| `command` | `enum` | 가능 |
| `help_id` | `str` | 불가 |
| `goal_revision` | `int` | 불가 |
| `actor_role` | `enum` | 불가 |
| `snapshot` | `HelpSnapshot` | 불가 |

### 결과 데이터

| 필드 | 타입 | null 허용 |
|---|---|---|
| `announcement` | `enum` | 가능 |
| `arrival_id` | `str` | 가능 |
| `end_requested` | `bool` | 불가 |
| `end_reason` | `enum` | 가능 |

도착 알림은 POST_CALL_AGENT에서 (help_id, mode_revision, goal_revision, arrival_id) 범위로 중복 제거한다. 양쪽 역할의 종료 종류를 서로 바꿔 처리할 수 없다.

## 결과 상태와 실패 처리

| 반환 상태 | 업무 결과 | 발생 조건 | 처리 원칙 |
|---|---|---|---|
| `success` | `arrival_announced` | POST_CALL_AGENT의 최신 새 도착 추정 | 자녀에게 알림 1회, 도움은 활성 |
| `success` | `end_requested` | 등록 자녀의 완료 또는 부모의 중단 | N-23 호출 1회 |
| `success` | `duplicate_ignored` | 이미 처리한 알림/명령 ID | 알림 및 종료 이벤트 재발행 금지 |
| `error` | `null` | 권한 위반·이전 help_id/goal_revision | 다른 도움은 유지 |
