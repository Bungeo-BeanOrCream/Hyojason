# N-22 · resolve_arrival_or_completion

- **위치와 담당** D · 제어 서버
- **상위 노드** [B-07](../big-nodes/B-07.md)
- **상태** 설계. 구현 및 시연 환경 검증 필요.

도착 추정과 자녀 최종 완료, 부모 안내 끄기를 독립적으로 처리한다.

| 경계 | 계약 |
|---|---|
| 입력 | Zoro ArrivalDecision, 서버 상태, 도움 완료 또는 중단 요청 |
| 출력 | arrival.suspected/revoked, HelpEndRequested(reason), duplicate/stale result |

## 처리 규칙

- 현재 goal_revision과 부합하는 도착에서 알림을 한 번 발행한다. 증거가 무효가 되면 알림을 갱신한다.
- 인증된 자녀는 활성 도움에서 도착 알림 전에도 완료를 선택할 수 있다. 부모님 안내 끄기는 별도 종료 이벤트로 수락한다.
- 사용자 이벤트 대상 help_id/revision을 검증하고 동시·중복으로 두 번 종료되지 않도록 원자적으로 승인한다.

## 오류 및 보류

역할이 잘못된 요청, 다른 도움과 재연결 이전의 완료 신호, 구식 revision은 거절하고 현재 상태를 안내한다.

## 구현 완료 기준

도착 알림만 발생하면 도움 활성, 자녀 완료 버튼을 누르면 종료, 두 번 누른 경우 하나의 종료만 확인.
